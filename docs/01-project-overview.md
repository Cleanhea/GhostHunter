# 01. 프로젝트 개요

## 한 줄 정의

1인칭 시점에서 **가구를 조준해 홀드로 붙잡고, 마우스 방향으로 밀쳐 날리는** 멀티플레이 프로토타입.

## 이 프로토타입으로 검증하려는 것

1. **던지기 손맛** — 오버워치 루시우의 밀쳐내기처럼, 대상이 마우스 방향을 따라 위로 붕 뜨는 감각이 재미있는가.
   - 레퍼런스: https://www.youtube.com/shorts/0ZCbaVelhp8
2. **2인 협력 던지기** — 두 명이 같은 가구를 붙잡았을 때의 상호작용이 성립하는가.
3. **네트워크 물리 동기화** — Steam(Facepunch) 기반 P2P에서 물리 오브젝트가 두 클라이언트에게 납득 가능하게 보이는가.

재미없다는 결론이 나와도 성공한 프로토타입이다. 목표는 **판단할 수 있는 상태를 빨리 만드는 것**이지 완성도가 아니다.

## 범위 (In Scope)

| # | 항목 | 설명 |
|---|---|---|
| 1 | 1인칭 이동 + 멀티플레이 동기화 | WASD 이동, 마우스 시점, 점프. 2인 접속 |
| 2 | 벽 1개 배치 | 던진 가구가 부딪힐 기준물. 그냥 큐브 하나 |
| 3 | 가구용 큐브 1종 | 던져지는 대상. 프리미티브 큐브 + Rigidbody |
| 4 | 조준 타겟팅 + 윤곽선 | 크로스헤어 레이캐스트로 대상 지정. 범위 판정이 아니라 **타겟팅** |
| 5 | 홀드 방식 던지기 | 버튼을 누르고 있는 동안 부양·차징, 떼면 발사 |
| 6 | 2인 흡착 | 두 명이 같은 가구를 잡으면 강화. 혼자여도 던질 수 있음 |
| 7 | 가구 간 물리 효과 | 날아간 가구가 다른 가구를 쳐서 밀어내는 연쇄 |

## 범위 밖 (Out of Scope)

프로토타입에서 **하지 않는다.** 요청받아도 먼저 확인할 것:

- 게임 루프 / 승패 조건 / 점수
- 유령, 적, AI, 내비메시
- 캐릭터 모델, 애니메이션, 리깅 (캡슐로 충분)
- 사운드, 파티클, 포스트 프로세싱 튜닝
- 3인 이상 접속, 매치메이킹, 재접속 처리
- 클라이언트 예측/롤백 (호스트 권위 + 보간으로 시작)
- 최적화, 빌드 파이프라인, CI

## 핵심 설계 결정

| 결정 | 선택 | 이유 |
|---|---|---|
| 네트워크 토폴로지 | **호스트 권위(client-server, 호스트가 서버 겸업)** | 물리 권위를 한 곳에 두면 프로토타입 난이도가 급감 |
| 트랜스포트 | Steam P2P (Facepunch 래퍼) | 포트포워딩 없이 친구와 바로 테스트 가능 |
| 던지기 입력 | **홀드** (누르는 동안 유지, 떼면 발사) | 2인 흡착 타이밍을 맞추려면 지속 상태가 필요 |
| 대상 선택 | **레이캐스트 타겟팅** (범위 판정 아님) | 어떤 가구를 대상으로 삼았는지 명확해야 협력이 성립 |
| 힘의 방향 | 카메라 조준 피치 + 수평 기준 20°~70° 보정 | 아래로 박히거나 수직으로 뜨지 않는 일정한 궤적 |

## 용어

- **홀드(Hold)** — 던지기 버튼을 누르고 있는 상태. 가구가 허공에 부양한다.
- **흡착(Attach)** — 특정 가구의 홀더 슬롯을 점유한 상태. 가구당 최대 2슬롯.
- **부양(Hover)** — 홀드 중 가구가 중력을 무시하고 조준점 앞에 떠 있는 상태.
- **발사(Launch)** — 입력 해제로 가구에 속도 변화가 적용되어 날아가는 순간.
