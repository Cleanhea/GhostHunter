## 2. 개요 [확정 — 원문]

- 인커는 벽(또는 문)에 **명령 글씨**를 쓰는 귀신이다. 예: "Don't turn around", "Don't jump".
- 플레이어는 글씨를 **전부 닦아** 명령을 해제하거나, 닦기 전까지 명령을 지켜야 한다.
- 명령 글씨를 남기는 초자연현상은 2종이다.

| # | 현상 | 남기는 글씨 | 발생 확률 | 재발동 제한 |
| --- | --- | --- | --- | --- |
| 1 | [문틈으로 지켜보는 귀신](#4-현상-1--문틈으로-지켜보는-귀신-확정--원문) | 문에 "**I SEE YOU**" | 플레이어가 방에 들어가 있으면 20% | 3번 겪으면 더 발생하지 않음 |
| 2 | [귀신이 직접 글씨를 쓰는 모습](#5-현상-2--귀신이-직접-글씨를-쓰는-모습-확정--원문) | 벽에 기존 등록 문구 중 하나(예: "DON'T JUMP.") | 플레이어가 방에 들어가 있으면 30% | 2번 겪으면 더 발생하지 않음 |

확률을 언제 굴리는지·횟수를 누구 기준으로 세는지는 IK-9·IK-10.

## 3. 명령 글씨 공통 규칙 [확정 — 원문]

메모 "말을 거는 귀신"과 기획서의 "기존 명령 글씨 규칙"을 합친 것이다. 현상 1·2가 남기는 글씨는 모두 이 규칙을 따른다.

| 상태 | 결과 |
| --- | --- |
| 글씨를 **전부 닦았을 때** | 명령이 해제된다 — 명령을 무시해도 된다 |
| 닦지 않은 상태에서 **명령을 위반했을 때** | 정신력 **10%** 감소 → 귀신이 화낸다(**갑툭튀**) → 글씨는 **자동으로 사라진다** |

- 글씨는 닦기 전까지 사라지지 않는다.
- 위반하면 글씨가 자동으로 지워지므로, 같은 글씨로 두 번 벌을 받지 않는다.
- 귀신이 글씨를 쓰는 중에는 청소와 위반 판정을 하지 않는다(현상 2).

| 정해지지 않은 것 | → |
| --- | --- |
| 명령 문구 목록과 문구별 위반 판정 기준 | IK-2 |
| "I SEE YOU"(현상 1)는 무엇을 금지하는가 | IK-3 |
| 명령을 지켜야 하는 사람·벌받는 사람 | IK-4 |
| "10%"의 기준(0~100 척도에서 10 vs 현재 값의 10%) | IK-5 |
| 갑툭튀 연출 | IK-6 |
| 닦는 방법·"전부 닦음" 판정 | IK-7 |
| 글씨 여러 개 동시 존재·어택 타임 중 명령 유지 | IK-8 |

## 4. 현상 1 — 문틈으로 지켜보는 귀신 [확정 — 원문]

### 4.1 개요

- 플레이어가 청소하는 도중 닫힌 문이 천천히 열리고, 문틈에서 귀신이 얼굴을 내밀어 플레이어를 바라본다.
- 플레이어와 눈이 마주치면 귀신이 고개를 기울이고, 문이 갑자기 닫힌다.
- 이후 문 바깥에서 긁는 소리가 들리고 문에 "**I SEE YOU**"라는 글씨가 나타난다.
- 플레이어는 그 글씨를 닦아야 한다.

### 4.2 발동 조건

| 항목 | 조건 |
| --- | --- |
| 플레이어 거리 | 문으로부터 2~6m |
| 문 상태 | 닫힌 상태 |
| 시야 | 플레이어 카메라에서 문이 보이는 상태 |
| 문 주변 | 문 반경 1m 이내 플레이어 없음 |
| 귀신 상태 | 어택 타임이 아닌 상태 |
| 추가 조건 | 문을 다른 플레이어가 조작 중이지 않을 것 |
| 확률 | 플레이어가 방에 들어가 있으면 **20%** → IK-9 |
| 재발동 제한 | **3번** 겪으면 더 발생하지 않는다 → IK-10 |

### 4.3 진행

| 순서 | 진행 내용 | 시간 |
| --- | --- | --- |
| 1 | 문이 천천히 20° 열린다. | 2초 |
| 2 | 열린 문틈 사이로 귀신이 얼굴을 내민다. | 1초 |
| 3 | 귀신이 플레이어를 바라보며 대기한다. | 최대 5초 |
| 4 | 눈이 마주치면 귀신이 고개를 30° 기울인다. | 0.5초 |
| 5 | 귀신이 문 뒤로 사라지고 문이 세게 닫힌다. | 0.5초 |
| 6 | 문 바깥에서 긁는 소리가 들리며 글씨가 나타난다. | 2초 |

#### 4.3.1 세부 판정

- **눈 맞춤:** 플레이어 카메라 정면 15° 이내에 귀신 얼굴이 0.3초 이상 들어오면 성공 → 가림·다인 처리 IK-15.
- 5초 이내에 눈이 마주치지 않으면 4단계를 생략하고 5단계로 진행한다.
- 현상이 시작되면 그 문의 상호작용은 현상이 끝날 때까지 비활성화한다.

### 4.4 플레이어·오브젝트에 미치는 영향

| 대상 | 영향 |
| --- | --- |
| 플레이어 | 이동 및 행동 제한 없음 |
| 정신력 | 눈이 마주치면 **−5** / 문 앞에서 글씨를 발견하면 **−3** → 공통 목격 감소와의 관계 IK-13 |
| 귀신 | 문틈에서 얼굴과 상체 일부만 노출 → IK-14 |
| 문 | 자동으로 열림. 현상 중에는 열고 닫기 상호작용 불가 |
| 글씨 | 명령 글씨 공통 규칙(§3)으로 작동 |

### 4.5 종료·재발동

- 문이 완전히 닫히면 귀신 오브젝트를 비활성화한다.
- 문에 나타난 글씨는 닦기 전까지 사라지지 않는다.
- 닦지 않은 상태에서 명령을 위반하면 정신력 10% 감소와 갑툭튀 연출이 발생하고, 글씨는 자동으로 제거된다(§3).
- **진행 중 어택 타임이 시작되면** 글씨와 귀신을 제거하고 문을 원래 닫힌 상태로 복구한다 → 현상이 끝난 뒤 남은 글씨의 처리는 IK-18.
- 플레이어가 방에 들어가 있으면 20% 확률로 발생하며, 3번 겪으면 재발동되지 않는다.

### 4.6 연출·리소스

| 구분 | 필요 리소스 |
| --- | --- |
| 귀신 애니메이션 | 문틈에서 얼굴 내밀기, 고개 기울이기, 뒤로 숨기 |
| 문 애니메이션 | 천천히 열기, 빠르게 닫기 |
| 사운드 | 문 열리는·닫히는 소리, 긁는 소리 |
| 시각 효과 | 문 표면에 "I SEE YOU" 글씨 표시 → 문 어느 면인지 IK-16 |

사운드 파일은 §7.

## 5. 현상 2 — 귀신이 직접 글씨를 쓰는 모습 [확정 — 원문]

### 5.1 개요

- 플레이어가 방에 들어가면 귀신이 벽을 향해 서서 손가락으로 명령 글씨를 쓰고 있다.
- 플레이어가 쳐다보면 귀신이 글씨 쓰기를 멈추고, 몸을 돌리지 않은 채 목만 돌려 플레이어를 바라본다.
- 귀신이 사라지면 벽에 명령 글씨가 남으며, 플레이어는 그 글씨를 닦아야 한다.

> **2026-11-16 사용자 결정 — 귀신 모습을 없앴다.** "귀신이 글 쓰고 나 보는 기믹 없애고 그냥 허공에 글만 쓰는 느낌으로".
> 벽 앞에 선 귀신·목 180° 회전·응시·소멸(§5.3 ①·③~⑤)은 구현하지 않는다 — 글씨만 4초 동안 저절로 써지고, 다 쓰면 현상이 끝나며
> 바로 명령 글씨가 된다. 발동 조건·2m 접근 시 즉시 완성·명령 규칙은 그대로다. 아래 원문은 기록으로 둔다.

> **원문 안 어긋남.** 개요는 "쳐다보면 쓰기를 멈춘다", 진행표(§5.3)는 "4초 동안 다 쓴 뒤 멈춘다", 세부 판정은
> "2m 안으로 다가오면 즉시 완성한다"고 적었다. 쳐다보는 것만으로 쓰기가 끊기는지 → IK-11.

### 5.2 발동 조건

| 항목 | 조건 |
| --- | --- |
| 플레이어 거리 | 글씨 생성 지점으로부터 2~7m |
| 시야 | 플레이어 카메라에서 글씨 생성 지점이 보이는 상태 |
| 벽 상태 | 지정된 글씨 생성 지점이 비어 있을 것 → 지점 정의 IK-17 |
| 귀신 상태 | 어택 타임이 아닌 상태 |
| 추가 조건 | 해당 지점에 기존 명령 글씨가 없을 것 |
| 확률 | 플레이어가 방에 들어가 있으면 **30%** → IK-9 |
| 재발동 제한 | **2번** 겪으면 더 발생하지 않는다. 같은 원문 §3-5에 "재발동은 공통 발동 규칙을 따른다"도 있다 → IK-10 |

### 5.3 진행

| 순서 | 진행 내용 | 시간 |
| --- | --- | --- |
| 1 | 귀신이 벽을 향해 선 상태로 등장한다. | 즉시 |
| 2 | 손가락으로 벽에 명령 글씨를 쓴다. | 4초 |
| 3 | 글씨 작성이 끝나면 귀신이 움직임을 멈춘다. | 즉시 |
| 4 | 귀신의 목이 180° 돌아가며 플레이어를 바라본다. | 1초 |
| 5 | 귀신이 플레이어를 3초간 응시한 뒤 사라진다. | 1초 → IK-12 |
| 6 | 벽에 남은 글씨가 명령 글씨(§3)로 활성화된다. | 즉시 |

#### 5.3.1 세부 판정

- 글씨 작성 중 플레이어가 귀신에게 **2m 이내**로 접근하면 작성 속도를 높여 즉시 글씨를 완성한 뒤 4단계로 넘어간다.
- 귀신의 고개는 **발동 대상 플레이어**를 향하도록 회전한다.
- 글씨 작성 중에는 청소 및 명령 위반 판정을 비활성화한다.
- 명령 글씨는 등록된 문구 중 하나를 사용한다. 예: "DON'T JUMP." → 문구 목록 IK-2.

### 5.4 플레이어·오브젝트에 미치는 영향

| 대상 | 영향 |
| --- | --- |
| 플레이어 | 이동 및 행동 제한 없음 |
| 정신력 | **현상 자체로는 감소 없음** → 공통 목격 감소와의 관계 IK-13 |
| 귀신 | 글씨 작성 후 고개 회전, 소멸 → IK-14. **2026-11-16 사용자 결정으로 귀신 모습 없음** — 글씨만 써진다(§5.1 위 상자) |
| 벽 | 명령 글씨 생성 |
| 글씨 | 명령 글씨 공통 규칙(§3)으로 작동 — 전부 닦으면 해제, 닦지 않고 위반하면 정신력 10% 감소·갑툭튀·글씨 자동 제거 |

### 5.5 종료·재발동

- 남겨진 명령 글씨는 초자연현상과 별개로 유지한다.
- **진행 중 어택 타임이 시작되면** 귀신을 즉시 제거한다.
  - 글씨 작성 완료 전: 작성 중인 글씨를 제거한다.
  - 글씨 작성 완료 후: 글씨를 유지하고 명령 글씨로 활성화한다.
- 플레이어가 방에 들어가 있으면 30% 확률로 발생하며, 2번 겪으면 재발동되지 않는다.

### 5.6 연출·리소스

| 구분 | 필요 리소스 |
| --- | --- |
| 귀신 애니메이션 | 벽에 글씨 쓰기, 손 멈추기, 고개 180° 회전 |
| 글씨 연출 | 손가락 이동에 맞춰 글씨가 순차적으로 나타나는 효과 |
| 사운드 | 손톱으로 벽을 긁는 소리, 목 회전 효과음 |
| 시각 효과 | 귀신 소멸 효과 |
| 시스템 연동 | 명령 글씨 생성·청소·위반 판정(§3) 재사용 |

사운드 파일은 §7.

## 6. 공통 규칙과의 관계

| # | 구현에서 택한 값 |
| --- | --- |
| IK-1 | 별도 귀신 종류(설정 타입). 어택 중 고유 기믹은 없다 — 공통 어택 그대로 |
| IK-2 | **2026-11-15 사용자 요청으로 명령 4개** — 기존 2개에 "DON'T OPEN THE DOOR"(문 열지 마)·"DON'T TOUCH THE FURNITURE"(가구 만지지 마)를 더했다. 현상 2가 켜진 명령 중 고르게 고른다. **문 열기** = 플레이어가 닫힌 문을 여닫기로 열었다(닫는 것·귀신이 연 것은 아님). **가구 만지기** = 가구를 잡기 시작했거나 드라이버로 분해했다(밀치기·부딪힘은 아님). 처음 2개(2026-11-14): 문구 "DON'T TURN AROUND"·"DON'T JUMP". **뒤돌기** = 1초 안에 몸 방향이 135° 이상 바뀜 — 천천히 둘러보기·±60° 흔들기는 위반이 아니다. **점프** = 실제로 뛴 횟수(`PlayerMotor.JumpCount`, 소유자 복제) |

| IK-5 | 개인 정신력 **−10**(0~100 척도) |
| IK-6 | 위반한 사람 화면에만 눈앞 0.7m(벽·가구가 더 가까우면 그 앞, 최소 0.3m)에 귀신 몸을 0.8초 떨리게 띄우고 합성 비명을 낸다. **어두운 집에서도 보이게**(2026-11-16 사용자 요청) 몸이 스스로 빛나고(발광) 턱 아래 앞쪽에 깜빡이는 점광원을 단다. 공통 목격 감소는 붙이지 않는다 |
| IK-7 | **대걸레 좌클릭 6번**(얼룩과 같은 조준 거리 3m·요청 간격, 다 쓴 글씨만). 닦을수록 흐려진다. 청소 진행도에는 넣지 않는다 |
| IK-8 | 글씨마다 명령이 따로 걸린다(최대 16개, 넘으면 오래된 것부터 지운다). 어택 중에도 남은 글씨와 위반 판정은 그대로다 |
| IK-9 | 어택이 아닐 때(활동·자연 진정, 경고 제외) **10초마다** 두 현상 순서를 섞어 각자 확률을 굴린다. "방에 들어가 있다" = 집 안·세이프 존 밖·은신하지 않은 생존자. 공통 §6 현상은 인커에 없다(2026-11-15) |
| IK-10 | 횟수는 귀신 한 마리(한 판) 기준 팀 전체로 센다. Hub 강제 실행은 세지 않는다 |
| IK-11 | 쳐다봐도 끊지 않고 4초 다 쓴다. 2m 접근만 즉시 완성(접근 기준은 글씨 앞 바닥). 다 쓰면 끝난다 — 귀신 모습이 없어 "쳐다보면 멈춘다"는 해당 없음(2026-11-16) |
| IK-12 | 해당 없음 — 응시·소멸 단계를 없앴다(2026-11-16 사용자 결정) |
| IK-13 | 원문 값이 공통 G-6(현상 목격 −5)을 **대신한다** — 인커 현상은 G-6 판정을 부르지 않는다. 현상 2는 감소 없음. 인형은 실제 본체가 아니라 본체 목격 −5/5초(G-17)도 없다. 글씨 발견 −3 은 플레이어마다 한 번 |
| IK-14 | **연출 전용 인형**(현상 1 문틈·갑툭튀만 — 현상 2는 귀신 모습 없음, 2026-11-16) — 각 피어가 귀신 몸 모델을 복제해 세운다(충돌·판정 없음). 실제 귀신 본체는 숨은 채 배회한다. 고개 기울기는 이름에 "head" 가 든 뼈를, 없으면 모델 전체를 돌린다 |

| IK-16 | 대상 플레이어 쪽 면. 글씨는 문을 따라 돈다 |
| IK-17 | 지정 지점 대신 대상 플레이어 정면 ±45° 를 11갈래로 훑어 2~7m 의 세로 벽(문·움직이는 물체 제외)을 찾는다. 귀신이 벽 앞 0.5m 에 설 자리(같은 층 바닥·빈 공간)와 기존 글씨와 1.2m 이격을 확인한다 |
| IK-18 | 다 쓴 "I SEE YOU" 는 어택이 와도 남는다(현상 2와 같게) |

그 밖의 구현 사항:

- **문 잡기** — 현상 1 동안 `DoorInteractable` 이 귀신 잡기 상태(잠금·틈 각도·여는 속도)를 복제한다. 잡힌 동안 플레이어 여닫기 RPC와
  귀신 AI 의 문 열기·현상 #4 를 거절한다. 끝나면 닫힌 채로 놓는다.
- **글씨 표시 — 피로 쓴 글씨(2026-11-15, 사용자 "지금 연출 너무 거지같아. 피로 쓰이는 느낌으로").** 글꼴 텍스처 대신 손글씨 획을 손가락으로 긋듯
  차례로 그린다. 획 시작에 피가 고이고, 끝으로 갈수록 말라 갈라지며, 쓴 자리에서 피가 흘러내려 방울이 맺힌다. 튄 방울도 있다. 글자마다 기울기·크기가 조금씩 다르다.
  닦을수록 갈색으로 번지며 흐려진다. 긴 명령은 한 줄 2.4m 를 넘으면 낱말 단위로 2~3줄에 쓴다("DON'T TOUCH / THE FURNITURE"), 문에는 문짝 폭에 맞춘다("I SEE / YOU").
  조명 영향을 받지 않아 어두운 집에서도 보인다(색은 어둡게).
- **현상 2 — 귀신 없이 글씨만(2026-11-16, 사용자 "귀신이 글 쓰고 나 보는 기믹 없애고 그냥 허공에 글만 쓰는 느낌으로").** 귀신 인형을 세우지 않는다 —
  피 글씨가 4초 동안 저절로 써지고, 젖은 문지름 소리가 지금 써지는 손끝을 따라 옮겨 간다. 다 쓰면(또는 2m 안으로 다가오면 즉시 완성) 현상이 끝나고 바로 명령 글씨가 된다.
  목 돌리기·응시·소멸 단계와 목 꺾임 소리·충격 연출은 없앴다. 같은 날 먼저 넣었던 "쓰는 동안만 몸 숨김"은 이것으로 대체했다.
- **화면 연출(포스트프로세싱, 2026-11-15)** — 현상이 진행되는 동안 가까이 있는 플레이어 화면이 잿빛으로 빠지고 가장자리가 검붉게 조이며(심장 박동처럼) 필름 잡음이 낀다.
  문이 열릴수록·귀신과 눈이 마주칠수록·벽 글씨가 써질수록 진해지고, 고개 기울임·문 쾅 순간에는 화면이 붉게 일그러지는 충격이 온다. 명령을 어긴 사람은 갑툭튀와 함께 가장 센 충격을 받는다.
  현상 위치에서 6m 안이면 최대, 16m 밖이면 없다(설정 에셋 "Inker 연출"). [임시] 세기·색은 원문에 없다.
- **소리** — 원문 mp3(§7)가 없어 임시 합성음(`InkerSounds`)을 쓴다: 문 삐걱·쾅·긁기(피치 낮게)·**젖은 피를 문지르는 소리**(2026-11-15, 손톱 긁기에서 교체)·목 꺾임·비명. 오디오 서비스·믹서를 거치지 않는다.
- **호스트 이전** — 귀신 종류는 스냅샷(`GhostState.TypeIndex`)에 담아 같은 종류로 다시 스폰한다. 인커 글씨·진행 중 현상·횟수는 담지 않는다(이전 뒤 처음부터).
- `NetProtocolVersion` 11 → 12(글씨 목록·진행 상태·문 잡기·점프 횟수 복제, 대걸레 글씨 닦기 RPC, 갑툭튀 RPC). 2026-11-15 12 → 13(글씨 글자 높이·줄바꿈 폭, 명령 2종).

**자동 검증(2026-11-14):** EditMode 755/755(새 `GhostInkerTests` 20건), PlayMode 새 `GhostInkerFlowTests` 7/7. 세부는 [ghost-prototype.md](../architecture/ghost-prototype.md).

**미검증:** 실제 Stage1 화면(인형 자세·문틈 위치·글씨 크기와 읽는 방향), 다인 클라이언트 연출·RPC, 실제 마우스 회전의 뒤돌기 체감, 합성음 체감.
Stage1 문은 처음에 열려 있어(`_startsOpen`) 현상 1은 플레이어가 문을 닫아야 자연 발동한다 — Hub 강제 실행은 열린 문도 닫고 시작한다.

| IK-2 | **명령 문구 목록과 위반 판정.** 원문 예시는 "Don't turn around"·"Don't jump"·"DON'T JUMP." 뿐이다. 전체 목록, 문구별 위반 기준(예: 뒤돌아봄 = 카메라가 몇 도·몇 초 돌면 위반인가, 점프 = 점프 입력), 영어 표기 여부, 현상 2가 문구를 고르는 방식(무작위 등) | 위반 판정·글씨 표시 |
| IK-3 | **"I SEE YOU"의 명령.** 현상 1의 글씨는 무언가를 금지하는 문장이 아닌데 원문은 "기존 명령 시스템과 동일하게 작동"한다고 적었다. 무엇을 하면 위반인가(위반 없이 닦기만 하는 글씨인가, 다른 명령을 함께 거는가) | 현상 1 글씨 |
| IK-4 | **명령 대상.** 명령을 지켜야 하는 플레이어가 전원인가, 발동 대상인가, 글씨를 본 사람인가, 같은 방에 있는 사람인가. 위반 시 정신력 감소·갑툭튀를 받는 사람이 위반자뿐인가 | 위반 판정·다인 |
| IK-5 | **정신력 10%의 기준.** 0~100 척도에서 10을 깎는가, 현재 값의 10%인가. 개인 정신력인가 | 정신력 감소 |
| IK-6 | **갑툭튀 연출.** 원문은 "기존 갑툭튀 연출"이라 했지만 저장소에는 그 이름의 연출이 없다. 가장 가까운 것은 초자연현상 프로토타입의 "일시 출현"이다. 무엇을 보여주는가, 그때 공통 목격 감소(G-6·G-17)가 추가로 붙는가 | 위반 연출 |
| IK-7 | **닦기.** 대걸레로 얼룩처럼 닦는가, 다른 도구·맨손인가. 닦는 데 걸리는 양·시간, "전부 닦음" 판정, 일부만 닦인 상태 표시, 청소 진행도(공통 G-22 40% 트리거 포함)에 들어가는가 | 청소 연동 |
| IK-8 | **글씨 여러 개·어택 중 명령.** 글씨가 동시에 여러 개면 명령도 여러 개가 걸리는가. 어택 타임 동안 남아 있는 글씨의 명령·위반 판정은 유지되는가 | 명령 관리 |
| IK-9 | **발생 확률 판정.** "플레이어가 방에 들어가 있으면 20%/30%"를 언제 굴리는가(방에 들어갈 때 한 번, 주기마다 등). "방"의 기준(맵 생성의 Room). 공통 초자연현상 선정 루프(§6.4)와의 관계 | 발동 |
| IK-10 | **재발동 제한.** "3번(현상 2는 2번) 이상 겪으면 재발동되지 않는다"의 횟수를 플레이어별로 세는가, 판(스테이지)별로 세는가. 현상 2는 같은 절에 "재발동은 공통 발동 규칙을 따른다"도 있어 두 문장의 관계가 불분명하다 | 발동 |
| IK-11 | **현상 2 — 쳐다보면 멈추는가.** 개요("쳐다보면 쓰기를 멈춘다")와 진행표("4초간 다 쓴 뒤 멈춘다")가 다르다. 쳐다볼 때 미완성 글씨로 멈추는가(그 글씨도 명령이 되는가), 끝까지 쓰고 돌아보는가 | 현상 2 진행 |
| IK-12 | **현상 2 — 5단계 시간.** "3초간 응시한 뒤 사라진다 / 1초"가 응시 3초 + 소멸 1초인가 | 현상 2 연출 |
| IK-13 | **공통 목격 감소와의 관계.** 현상 1 눈 맞춤 −5가 공통 초자연현상 목격 −5(G-6)를 대신하는가, 더해지는가. 현상 2 "감소 없음"이 G-6·본체 목격 −5/5초(G-17)를 끄는 예외인가. 현상 1 "글씨 발견 −3"의 발견 기준(거리·시야·가림)과 1회만인지 | 정신력 감소 |
| IK-14 | **어택 밖 본체 노출.** 두 현상 모두 어택이 아닐 때 귀신 몸을 보여준다. 공통 구현은 본체를 어택에만 노출한다. 실제 귀신 본체가 그 자리로 오는가, 연출 전용 모델인가 | 귀신 표시 |
| IK-15 | **현상 1 — 눈 맞춤 판정.** 벽·가구에 가리면 실패인가. 여러 명이 있을 때 발동 대상만 판정하는가, 누구든 눈이 마주치면 성공인가. −5는 눈 맞춘 사람만 받는가 | 눈 맞춤 |
| IK-16 | **현상 1 — 글씨가 생기는 면.** "문 바깥에서 긁는 소리가 들리며" 글씨가 나타난다. 플레이어 쪽 면인가, 반대쪽(바깥) 면인가. "방에 들어가 있다면"에서 그 문이 플레이어가 있는 방의 문인가 | 글씨 위치 |
| IK-17 | **현상 2 — 글씨 생성 지점.** "지정된 글씨 생성 지점"을 레벨에 미리 배치하는가(씬 마커), 벽 표면을 자동으로 찾는가. 방마다 몇 개인가 | 레벨 배치 |
| IK-18 | **현상 1 — 끝난 뒤 남은 글씨와 어택.** 원문은 "진행 중 어택이 시작되면 글씨와 귀신 제거"만 적었다. 현상이 끝난 뒤 남아 있는 "I SEE YOU"는 어택이 와도 유지되는가(현상 2는 완료된 글씨를 유지한다고 명시) | 어택 처리 |
