## 2. 개요 [확정 — 원문]

1. 플레이어가 **어택 타임에 귀신의 타깃이 된 상황**에서, 귀신이 **타깃 방향으로 돌진할 것이라는 예고**를 보낸다.
2. 이후 정해진 방향으로 돌진해 **플레이어를 공격하고 가구 내구도를 깎아 작업을 방해**한다. 플레이어는 **안전한 방향으로 돌진을 유도한 뒤 회피**하는 행동으로 대응한다.
3. 성공 여부는 **돌진 후 플레이어가 죽지 않고 생존하거나, 돌진한 방향의 가구 내구도**로 확인한다.

| 항목 | 내용 |
| --- | --- |
| 발동 조건 | 귀신 어택 타임 진입 |
| 공격 방식 | 타깃 플레이어를 추격한 뒤, 지정한 방향으로 돌진 |
| 방해 요소 | 플레이어 사망 및 가구 내구도 감소 |
| 대응 방법 | 돌진 방향을 유도한 뒤 회피하거나, 가구로 돌진 차단 |
| 성공 판정 | 플레이어 생존 및 가구 내구도 보존 |

원문의 평가 기준(규칙을 이해하면 대응을 계획할 수 있는가 / 위치·운반 중인 가구·팀원 배치에 따라 판단이 달라지는가 / 대응에 성공하면
작업 기회가 생기는가 / 알아챌 수 있는가 / 실수하고 배울 수 있는가)과 단점("신박하거나 새로운 기믹은 아님")은 원문 그대로다.
"기믹 설계 시 참고 사항" 표(행동 목록·학습 목표·귀신의 개입·대응 방법·전달 방법)는 [ghost-base.md §4](ghost-base.md)와 같은 내용이다.

## 3. 기믹 진행 [확정 — 원문]

| 단계 | 지속 시간 | 행동 |
| --- | --- | --- |
| ① 추격 | 8초 | 기존 어택 규칙에 따라 타깃 추격 (난이도에 따라 추격 속도 조정) |
| ② 돌진 준비 | 2초 | 제자리에서 정지 후 돌진 방향 결정 |
| ③ 돌진 | 충돌까지 | 확정된 방향으로 직선 돌진 |
| ④ 스턴 | 5초 | 돌진 종료 지점에서 행동 불가 |
| ⑤ 반복 | 어택 종료까지 | 스턴 해제 후 ①부터 반복 |

### 3.1 돌진 준비

| 구간 | 행동 |
| --- | --- |
| 최초 1.3초 | 추격 동안 마지막으로 타깃팅한 플레이어의 현재 위치를 향해 방향 조정 |
| 마지막 0.7초 | 돌진 방향 고정 (변경 불가) |
| 준비 종료 | 확정된 방향으로 즉시 돌진 |

- 준비 중 타깃이 사망하거나 은신해도 기존 타깃 및 방향 결정 규칙을 유지한다.
- 방향이 고정된 뒤에는 타깃의 위치와 관계없이 방향을 바꾸지 않는다.

### 3.2 돌진 충돌

| 충돌 대상 | 결과 |
| --- | --- |
| 플레이어 | 충돌한 플레이어 즉시 사망 |
| 가구 | 내구도 감소 후 돌진 종료 |
| 벽 / 구조물 | 돌진 종료 |
| 공통 | **첫 번째** 충돌 발생 시 돌진 종료 및 스턴 진입 |

- 돌진은 가구·플레이어·벽(구조물) 중 한 가지와 물리적으로 충돌할 때까지 이어진다. 동선 중간의 의자와 충돌하면 거기서 끝난다
  (충돌 여부에 따라 돌진 거리는 길어질 수도 짧아질 수도 있다).
- **가구 내구도 손실 = ⌊돌진 거리(m) × 5⌋**, 소수점 이하는 버리고 **손실값이 1 미만이면 1**.

### 3.3 수치와 예외

| 항목 | 값 |
| --- | --- |
| 추격 속도 | 난이도별 기존 어택 규칙 |
| 돌진 속도 | 쉬움 5m/s · **보통 7m/s** · 어려움 9m/s — 프로토타입에서 변경 가능성 있음. **2026-11-07부터 `GhostDifficulty`(에셋별 난이도, Default=보통)로 고른다** |
| 돌진 거리 | 첫 충돌 전까지 제한 없음 |
| 가구 내구도 손실 | ⌊돌진 거리(m) × 5⌋, 최소 1 |
| **어택 종료 예외** | 어택 시간(60초)이 끝나는 시점에 귀신이 돌진 준비·돌진 중이면, 남은 시간과 상관없이 **그 돌진까지 마친 뒤** 어택을 종료한다 (스턴 생략) |

## 4. 플레이어 대응 [확정 — 원문]

| 구분 | 내용 |
| --- | --- |
| 공격 예고 | 귀신이 정지하고 돌진 준비 동작 실행 |
| 회피 | 방향 고정 후 돌진 경로에서 벗어나기 |
| 유도 | 벽이나 가구가 없는 방향으로 돌진 유도 가능 |
| 차단 | 가구를 돌진 경로에 배치해 조기 종료 유도 — 단, 내구도가 깎이는 패널티 존재 |

## 6. 공통 규칙과의 관계

| 공통 규칙 | 박치기 공룡 |
| --- | --- |
| 활동·경고·자연 진정 (공통 §4.4·4.5·4.7) | **변경 없음.** 기믹은 어택 중에만 동작한다 |
| 어택 중 이동 (공통 §9) | **추격 단계(①)는 그대로.** 준비·돌진·스턴 단계는 이동·탐지·포획 판정을 이 기믹이 직접 맡는다 |
| 포획(근접 즉사) | **추격 단계에서만** 기존 규칙으로 동작한다. 준비·돌진·스턴 중에는 돌진 충돌만 플레이어를 죽인다 → BD-5 |
| 가구 내구도 (FD-7) | **이 귀신의 돌진에 한한 예외.** 일반적으로 귀신과 부딪친 가구는 내구도가 줄지 않지만(FD-7), 돌진으로 부딪친 가구는 §3.2 공식대로 줄어든다. 원문이 명시한 규칙이라 예외로 둔다 → [furniture-durability-system.md](furniture-durability-system.md) |
| 어택 종료 (공통 §7.5) | **시간 종료만** 준비·돌진 중이면 돌진 후로 미룬다(§3.3). 정신력 회복 조기 종료·강제 진정 아이템은 즉시 적용한다 → BD-8 |
| 쉬움 난이도 사망 종료 (공통 §4.6) | 변경 없음. 난이도 개념이 아직 없다 → G-23 |
| 드릴 카 세이프 존 | 변경 없음. 세이프 존·은신처·침대 밑 은신·굴착 중 플레이어는 돌진에 맞지 않는다 → BD-4 |
| 귀신-가구 물리 충돌 | 2026-11-07부터 귀신 몸은 가구와 물리 충돌한다([ghost-prototype.md](../architecture/ghost-prototype.md)) — 돌진이 가구에 "막히는" 것은 이 충돌 위에서 동작한다 |

## 7. 사이클 상세 (구현 기준)

```text
어택 시작 ─▶ ① 추격 8초 ──(타깃이 있으면)──▶ ② 준비 2초 ──▶ ③ 돌진 ──(첫 충돌)──▶ ④ 스턴 5초 ──▶ ① …
              기존 어택 규칙     │              앞 1.3초 방향 추적          직선 이동           행동 불가
                                │              뒤 0.7초 방향 고정          속도 7m/s
              어택 시간 종료 ───┴─ 준비·돌진 중이면 돌진 뒤에 종료 / 추격·스턴 중이면 즉시 종료
```

- **타깃.** 추격 중 마지막으로 타깃팅한 플레이어(`_target`)를 기억하고 그 **위치**를 매 틱 갱신한다. 그 플레이어가 죽거나 은신하거나 접속이 끊겨도
  마지막 위치를 그대로 쓴다. 한 번도 타깃팅한 적이 없으면 8초가 지나도 준비로 넘어가지 않고 추격을 이어 가다가 타깃이 생기면 곧바로 넘어간다 → BD-11.
- **돌진.** 방향은 수평(Y 0)이고 고정 시점의 값이다. 캐릭터 컨트롤러로 0.05초 이하 스텝으로 쪼개 움직인다(프레임이 길어져도 플레이어·얇은 벽을 건너뛰지 않게).
- **충돌 판정.** ① 플레이어: 귀신 중심과의 수평 거리 ≤ `DinoHitRadius`(0.7m) 이고 높이 차 ≤ 1.2m → 즉사 → ② 옆으로 부딪힌 콜라이더(법선 Y 0.5 이내)가 기록되고
  돌진 방향으로 의도한 이동의 80% 미만밖에 못 갔거나 **옆으로 15% 넘게 밀렸으면**(벽을 스침 — 2026-11-09 추가, 이전에는 25° 벽을 스치면 앞으로 82% 가서 통과하고 벽을 타고 휘었다) 막힘 → 부딪힌 콜라이더가 가구면 내구도 손실 → ③ 집 경계 밖으로 나가면 벽으로 본다 → ④ 부딪힘 보고 없이 0.3초 이상 20% 미만으로 못 가면 막힘으로 본다
  → ⑤ 8초를 넘기면 끝낸다(안전장치).
- **거리.** 돌진 시작부터 실제로 움직인 수평 거리의 누적이다 → BD-6.

## 8. 구현 상태

**구현(2026-11-07).** 구조·설정·검증은 [ghost-prototype.md "박치기 공룡" 절](../architecture/ghost-prototype.md).

| 항목 | 값 |
| --- | --- |
| 켜는 곳 | **설정 타입으로 정한다**(2026-11-09, ADR-0024) — `GhostDinoSettings` 에셋인 `GhostPrototypeSettings_Tutorial` 만 박치기. Default 는 기본 귀신. 이전(2026-11-07): Default 의 `_dinoChargeEnabled` 를 켬 |
| 켜고 끄기 | F2 튜닝 창 → 귀신 설정 "Dino ghost" 의 `Dino Charge Enabled` — 즉시 적용 |
| 수치 | 추격 8초 · 준비 2초 · 방향 고정 0.7초 · 스턴 5초 · 돌진 속도 난이도별 5/7/9m/s · 가구 피해 5/m · 충돌 반경 0.7m · 안전 상한 8초 (모두 설정 에셋) |

구현하며 **임시로 고른 해석**(원문에 없어 결정이 필요한 부분 — 아래 §9 표에 반영):

| 항목 | 구현에서 택한 값 |
| --- | --- |
| 난이도 속도 (BD-1) | **2026-11-07 반영** — `GhostDifficulty`(쉬움/보통/어려움)별 5/7/9m/s. 난이도는 에셋마다 하나(Default=보통, Tutorial=쉬움)이고 선택 UI는 없다(G-23). 추격 속도 조정은 수치가 없어 하지 않았다 |
| 예고 연출 (BD-2) | 모델·소리 리소스가 없어 **몸 조명**으로만 알린다 — 준비 중 노란빛이 빠르게 깜빡임, 돌진 중 흰빛 강하게, 스턴 중 푸른빛 어둡게. 귀신 몸은 준비 중 돌진 방향으로 돈다(붉은 원뿔도 함께 돈다) |
| 맞는 플레이어 (BD-4) | 일반 추격과 같은 기준(`CanChasePlayer`) — 세이프 존·은신처·침대 밑 은신·굴착 중·집 밖 플레이어는 맞지 않는다 |
| 준비·돌진·스턴 중 포획 (BD-5) | 근접 즉사 포획은 멈춘다. 준비 중 곁에 선 플레이어는 죽지 않고, 돌진 경로에 있어야 죽는다 |
| 돌진 거리 (BD-6) | 돌진 시작부터 실제 이동한 수평 거리 누적 |
| 문 (BD-7) | **닫힌 문은 구조물**이라 돌진이 끝난다(문을 부수지 않는다). 열린 문짝은 귀신과 충돌 무시 상태라 지나간다 |
| 어택 종료 (BD-8) | **시간 종료만** 돌진 뒤로 미룬다(`GhostStateMachine.HoldAttackEnd`). 정신력 회복 조기 종료·강제 진정은 즉시 — 돌진이 취소된다 |
| 가구 반응 (BD-12) | 부딪힌 가구는 내구도만 깎이고 밀리지 않는다. 시체(`Furniture` 레이어)는 내구도가 없어 부딪히면 그냥 멈춘다 |
| 호스트 이전 (BD-13) | 사이클 상태를 스냅샷에 넣지 않았다 — 복원 뒤 추격 단계부터 다시 시작한다 |

(귀신 넘을 턱 0.35m 아래 — 넘어가는지 확인용) / 남동 식탁 · **D** 서쪽 폭 1.8m 복도 끝 닫힌 문(BD-7) · 북쪽 소파.
검증: PlayMode `DinoTestSceneFlowTests` — 실제 흐름으로 씬을 열어 구성(가구 5·문 1·드릴카 없음)·박치기 설정(`GhostDinoSettings`)을 확인하고, 플레이어를 보호한 채
어택을 걸어 준비 중 5m 앞으로 옮긴 플레이어에게 4.3m 돌진 후 스턴하는 것을 확인했다. 경우 B·C 의 실제 결과는 아직 보지 않았다. 사용자 보고("준비동작도 없고 직선이 아니다") 뒤 같은 씬에서 매 프레임 위치로 다시 쟀다 — 준비 2초 이동 0.00m, 방향 고정 뒤 플레이어가 옆으로 4m 피해도 15.4m 직선(옆 벗어남 0.04m), 원으로 도망치는 플레이어(보호 없음)에게도 어택 8초 뒤 준비·직선 돌진. 다만 도망치는 경우 귀신이 장애물 곁에서 준비해 돌진이 0.7m 만에 벽에 막히는 일이 잦고, 예고는 몸 조명뿐이라 화면에서 단계가 잘 안 보일 수 있다(BD-2). F1 접속 HUD 귀신 상태에 `Dino Charge` 줄(추격 n/8s·준비·방향 고정·돌진 거리·스턴)을 추가했다.
