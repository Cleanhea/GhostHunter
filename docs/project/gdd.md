## 3. 플레이어

### 3.1 이동 / 조작

`Assets/InputSystem_Actions.inputactions`의 액션 이름 기준.

| 액션 | 바인딩 | 용도 |
| --- | --- | --- |
| `Move` | WASD / 좌스틱 | 수평 이동 (5 m/s) |
| `Sprint` | Left Shift / 좌스틱 누르기 | 달리기 — 이동 속도 ×`sprintMultiplier`(1.4 → 7 m/s). 웅크리는 중엔 무효 |
| `Crouch` | C / 게임패드 B | 웅크리기 — 이동 3.5 m/s, 캡슐·카메라 낮춤 |
| `Look` | Mouse Delta / 우스틱 | 시점 |
| `Jump` | Space | 점프 |
| `Attack` | 마우스 좌클릭 (**Press And Release**) | 가구 잡기/던지기 (조준 2 m) |
| `Interact` | E | 문 여닫기 (조준선 2.5m 안의 문) |
| `Prone` | Z (토글) | 엎드리기 — 침대 밑으로 기어 들어가는 3번째 자세 |
| `Burrow` | **T** | 굴착 스킬 — **확정(2026-09-05)**. 기획서의 E는 `Interact` 충돌로 채택하지 않았다 → [mole-skill-system.md §3.5](mole-skill-system.md) |
| `Detect` | **Q** | 탐지 스킬 — 로컬 소유자 화면에서 활성 `DetectionTargetMarker`를 5초 표시하고 종료 후 10초 대기 → [mole-skill-system.md §4](mole-skill-system.md) |
| **일시정지 메뉴** | **ESC** | **`Game` 씬에서 일시정지 메뉴 열기/닫기. `Time.timeScale`은 1로 유지한다 — 게임은 계속 돈다** |

> `Attack`은 홀드 방식이므로 Interaction을 `Press`로 두고 `started`/`canceled`를 각각 잡는다.
> `Hold` Interaction을 붙이면 최소 유지 시간 임계값이 생겨 짧은 탭이 씹힌다.

> **ESC는 `Player/Pause` 액션으로 구현됐다.** `PlayerLook`의 직접 ESC 커서 토글은 제거했고,
> 메뉴가 열고 닫을 때 커서를 관리한다(PM-3). 메뉴가 열린 동안에는
> **이동·시점·상호작용·던지기·스킬이 전부 잠긴다**(PM-1).
> 시스템 전체 규칙은 [일시정지 메뉴 시스템 기획서](pause-menu-system.md)가 권위다.

상세: [../architecture/player-controller.md](../architecture/player-controller.md)

### 3.2 능력 / 상태

| 능력 | 효과 | 쿨다운 | 네트워크 권위 |
| --- | --- | --- | --- |
| 가구 잡기/던지기 | 홀드 중 부양, 해제 시 발사 | `relaunchLockDuration` 2.0s | **Server** |
| 문 여닫기 | 열림/닫힘 토글 | 없음 | **Server** (거리 검증) |
| 이동·점프 | — | — | **Owner** ([ADR-0008](../architecture/decisions/ADR-0008-owner-authoritative-player-movement.md)) |
| **탐지 스킬** (Q) | 활성 마커만 5초간 옮길 가구(`#f9f871`)·닦을 얼룩(`#fc84b8`)로 표시. 시전자 화면 전용 | **10초** | 로컬 전용 (복제 없음) |
| **굴착 스킬** (T) | 5초 땅속 은신 → 종료 시 4m 도약. **조작 전부 잠김** | **10초** | **Owner** (프로토타입) |

두 스킬 공통 사용 판정: **① 생존 ② 그 스킬이 사용 중이 아님 ③ 재사용 대기 == 0** — 하나라도
거짓이면 입력을 버린다(대기열에 쌓지 않는다).

두더지 스킬 2종은 **기획서 1.0 기준이다.** 탐지는 로컬 상태 머신·활성 마커·공통 UI·시전 파란빛 오버레이까지,
굴착은 프로토타입 규칙까지 구현됐다. 공통 규칙·종료 조건·미결정 목록은
[두더지 스킬 시스템 기획서](mole-skill-system.md)가 권위다.

- **탐지**는 키(Q)·지속(5초)·색·공통 UI·시전 중 로컬 파란빛 오버레이가 구현됐다. 대상 판정은
  작업 시스템을 추측하지 않고 활성 `DetectionTargetMarker`만 사용하는 스캐폴드이며, 실제 청소·이사
  작업 연동은 MS-5다. 손·주머니·레이저 포인터 애니메이션은 MS-14다.
- **굴착**은 확정 규칙이 전부 구현됐다(2026-09-05) — 키 **T**, 조작 전부 잠금(시점·스킬 키만 허용),
  **귀신에게 이미 감지된 상태에서 매몰하면 땅속에서도 탐지·포획**. 굴착은 "추격을 끊는" 스킬이
  아니라 **들키기 전에 미리 숨는** 스킬이다.
- **굴착 쿨타임 수치**는 사용자 확정 **10초**이며, 두 스킬 공유/독립 여부만 MS-3 잔여다.

### 3.3 사망 후 관전 [핵심 요구 확정 / 구현 미착수]

사망하면 **특수능력을 사용할 수 없으며**, **자유시점**과 **생존 플레이어 1인칭 관전** 두 모드를 제공한다.
자유시점은 충돌·중력 없이 벽·바닥·천장 등을 통과하며 전후·좌우·상하로 이동한다.
특정 키로 생존 플레이어의 시점으로 전환해 위치와 시선 방향을 계속 따라가며 자유시점으로도 돌아올 수 있다.

세부 규칙·조작키/속도 등 TBD·기존 코드와의 차이·수용 기준은
[사망 후 관전 시스템 기획서](spectator-system.md)가 권위다. **승패·시체 생성·부활 규칙은 이번 확정 범위에 포함하지 않는다.**

## 4. 게임 모드 · 세션 흐름

```
[ 타이틀 ] → [ 로비 ] → [ 매치 ] → [ 결과 ] → 로비
```

| 단계 | 설명 | 씬 | 네트워크 상태 |
| --- | --- | --- | --- |
| 타이틀 | 방 생성(6자리 코드 발급), 방 코드 참가, 설정, 종료 | `Title` | 미접속 |
| 로비 | 방 코드·멤버 목록·준비·시작. 최대 4명 | `Lobby` | Steam Lobby만 (NGO 세션 없음) |
| 매치 | 맵 하나 = 라운드 하나. **라운드는 개별 매치다**(연속 진행 아님) | `Game` | Host/Client 연결됨 |
| 결과 | **TBD** — 승패 조건 확정 후 | `Result` | 정산 후 해산 |

**세션 시작 순서는 MUST `씬 로드 → StartHost → 로비 시작 신호`다.**
로비에서 바로 `StartHost` 하면 스폰 지점 없는 씬에 스폰되고, 신호를 먼저 보내면
게스트가 세션 없는 호스트에 접속한다.

- 방 코드: 6자리 커스텀 코드 (32자 문자셋, 혼동 글자 제외)
- 로비 가시성·난입: [ADR-0012](../architecture/decisions/ADR-0012-room-code-and-lobby-visibility.md) — **결정 대기**

### 5.1 요약

유령은 플레이어 조작 진영이 아닌 **적대 AI 시스템**이다(2026-08-23 확정).
집 하나당 기본 1마리가 집 내부에서만 활동하며, 평상시에도 실제 위치를 가지고 이동한다.
평소에는 초자연현상으로 작업을 방해하고, 조건을 만족하면 어택 타임에 진입해 탐지·추격·공격한다.

```text
[평상시] ↔ [활동] → 어택 판정 성공 → [경고 5초] → [어택 30~90초] → [자연 진정 30초] → 조건 재검사
                                                     └─ 탐지 → 추격 → 마지막 위치 7초 수색
```

| 상태 | 지속 | 공격 | 진입 |
| --- | --- | --- | --- |
| 평상시 | 조건 충족까지 | X | 게임 시작 |
| 활동 | 조건 유지 동안 | X | 팀 평균 정신력 80 이하 · 청소 40% 도달 · 귀신별 특수 조건 |
| 경고 | 5초 | X | 어택 판정 성공 |
| 어택 | 30~90초 (임시) | **O** | 경고 종료 |
| 자연 진정 | 30초 | X | 어택 종료 |
| 강제 진정 | 10초 | X | 아이템 사용 (별개 시스템) |

### 5.2 정신력 연동 요약

정신력의 정의·증감·디버프·UI는 [정신력 시스템 기획서](sanity-system.md)가 권위다.
귀신은 **생존 플레이어의 팀 평균 정신력**을 읽어 판정한다.

| 팀 평균 정신력 | 귀신 행동 | 10초당 어택 확률 (임시) |
| --- | --- | ---: |
| 81~100 | 정신력에 의한 활동 진입 없음 | 0% |
| 61~80 | 활동 가능 / 어택 불가 | 0% |
| 51~60 | 활동 + 어택 가능 | 20% |
| 41~50 | 〃 | 40% |
| 31~40 | 〃 | 60% |
| 0~30 | 어택 + 현상 빈도 증가 + 특수 능력 | 80% |

스테이지 시작 정신력은 **100%**다. 어택은 활동 상태 + 팀 평균 60 이하에서 **10초 주기 확률 판정**으로
발생하며, 저주받은 오브젝트 조작 등 특수 Trigger는 즉시 100% 발동한다 →
[ghost-system.md §7](ghost-system.md)

- **B안 가구 랜덤 배치 코드 구현(MAP-19)**: 임시 Sofa 2 / Drawer 3 / Chair 5 / Box 6을 별도 풀에서
  서버가 후보 지점으로 옮긴다. 수량·중복·충돌을 검사하며 선택된 가구만 Q 탐지 대상으로 표시한다.
  설정값은 조정 가능하다. 풀 16개·안전 후보 91개 저장 및 설치 내부 seed 0~15 검증 완료. C# 빌드 오류 0·순수 계획 테스트 13/13 통과, 네트워크 Play 검증은 대기다.
  상세·설치 절차는 [맵 생성 §10.1.3](../architecture/map-generation.md)에 있다.

### 6.2 v0.4 맵 생성·작업량 기준 (2026.09.12 반영)

| 항목 | 내용 |
| --- | --- |
| 고정 / 랜덤 | House·Floor·Room Slot 위치·중앙 홀·복도·계단·문·창문 위치는 고정. Room Preset·소형 Object·Target Type·Count는 랜덤, 청소·이삿짐·귀신 콘텐츠는 조건부 랜덤 |
