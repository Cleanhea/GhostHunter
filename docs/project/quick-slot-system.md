# 퀵슬롯(라디얼 휠) 시스템 기획서

## 1. 버전 관리

| 항목 | 내용 |
| --- | --- |
| 작성일 | 2026-09-12 |
| 상태 | **대걸레 장착·청소 연결.** 일반 인벤토리·소모품은 미구현. 초기 더미 범위에서 2026-09-12 청소 요청으로 확장 |

## 2. 개요

Sons of the Forest 식 홀드형 라디얼 퀵슬롯을 로컬 플레이어 HUD에 추가한다. Tab을 누르고 있는
동안 화면 중앙에 도넛형 링이 열리고, 마우스 델타를 누적한 방향으로 슬롯을 고른 뒤 Tab을 떼는
순간 확정한다.

> **이 문서의 범위가 아닌 것** — 인벤토리·아이템 시스템 자체(아직 미작성), 아이콘 에셋 제작.
> `QuickSlotItemDefinition.IsMop`으로 대걸레를 구분한다. 청소 규칙은 [cleaning-system.md](cleaning-system.md)를 따른다.

## 3. 사용자 확정 사항 (QS-1 ~ QS-10, 2026-09-12)

착수 전 10건을 사용자에게 확인했다. 답변은 전부 [확정]이며, 실제 인벤토리 시스템이 붙기 전까지는
아래 §4 범위 내에서만 구현됐다.

| # | 질문 | 확정값 |
| --- | --- | --- |
| QS-1 | 슬롯에 무엇이 들어가는가 | 초기 더미에서 **대걸레·맨손 선택**으로 확장(2026-09-12 청소 요청). 일반 인벤토리는 별도 작업 |
| QS-2 | 슬롯 개수·빈 슬롯 처리 | **4개.** 빈 슬롯은 가리킬 수 있으나 확정할 수 없다(레퍼런스 기본값 적용 — 사용자가 개수만 지정하고 빈 슬롯 규칙은 명시하지 않아 레퍼런스 기본값을 그대로 적용했다) |
| QS-3 | 확정(Tab 뗌) 시 동작 | **장착.** `PlayerCleaningController`를 통해 서버에 슬롯을 검증받고 소유자의 표시를 갱신한다 |
| QS-4 | 홀드 전용 / 짧은 탭 토글 | **홀드 전용만.** 탭 토글은 만들지 않는다 |
| QS-5 | 휠이 열린 동안 이동 허용 | **허용.** 시점(Look)은 항상 잠근다 |
| QS-6 | 선택·장착이 다른 플레이어에게 보이는가 | **아니오, 표시·대걸레 모델은 로컬 전용.** 장착 검증 RPC와 소유자 회신만 추가 |
| QS-7 | 게임패드 지원 범위 | **이번엔 KB/M 전용.** 우스틱 선택·숄더 홀드는 범위 밖 |
| QS-8 | 휠 열림 중 배경 연출 | **로컬 디밍만.** 시간 감속 연출(블러 등)은 없다 — 멀티라 서버 시간을 늦출 수 없다 |
| QS-9 | 굴착 중 / 가구를 잡은 중 열 수 있는가 | **둘 다 불가.** 조건이 깨지면 열려 있던 휠도 선택을 버리고 즉시 닫는다 |
| QS-10 | 아이콘 에셋 | **단색 도형 자리표시자.** 실제 아이콘이 생기면 `QuickSlotItemDefinition.Icon`에 넣으면 된다 |

## 4. 동작 규격 (구현 범위)

1. **열림 조건** — 살아 있는 로컬 플레이어(§7 참고) + 일시정지 아님 + 굴착 중 아님 + 가구를 잡고
   있지 않음. 열려 있다가 조건이 깨지면 선택을 버리고 즉시 닫는다(QS-9).
2. 열리는 순간 조작이 잠기고(§5), 누적 포인터가 0으로 초기화된다.
3. 매 프레임 누적 포인터 += 마우스 델타 × 감도, 링 반경으로 클램프 → 각도 계산 → 슬롯 인덱스.
4. Tab을 떼는 순간 인덱스가 유효하고 그 슬롯이 비어 있지 않으면 확정(장착 표시 갱신), 아니면
   무시한다(QS-2·QS-3).
5. 일시정지 메뉴가 열리면 휠은 무조건 닫힌다 — 메뉴 잠금이 이긴다.

## 5. 입력·잠금

`Player/QuickSlot` 액션(`<Keyboard>/tab`)을 신설했다. 입력 잠금은 세 번째 독립 잠금
(`PlayerInputReader.SetWheelInputLocked`)으로 구현했고, 우선순위는 **메뉴 &gt; 굴착 &gt; 휠**이다.
구현 세부는 [architecture/quick-slot.md](../architecture/quick-slot.md), 기존 두 잠금과의 관계는
[architecture/player-controller.md](../architecture/player-controller.md)를 본다.

## 6. 각도 규약

12시 방향이 0번 슬롯이고 시계 방향으로 증가하며, 슬롯 경계는 슬롯 중심 ±(360°/N/2)다. 순수
계산은 `QuickSlotSelection.Resolve`(EditMode 테스트 대상)에 있다.

## 7. 남은 것 (관전 연동 / 실제 인벤토리 후속)

| 항목 | 상태 |
| --- | --- |
| 아이템 목록·인벤토리 시스템 | **미작성.** 이 문서가 다루지 않는다 |
| 확정 시 서버 RPC·검증 | **대걸레 작업으로 연결됨.** 서버에서 로드아웃·생존·운반·매몰 여부 확인 |
| 사망 상태 게이팅 | **구현됨(SP-IMPL-1).** `ILocalPlayerContext.Sanity`로 검사하며 열린 휠은 사망 시 선택을 취소하고 닫는다 |
| 아이콘 에셋 | 자리표시자만(QS-10). 실제 에셋 준비 주체·시점은 미정 |
| 다른 플레이어에게 보이는 선택(QS-6 번복 여부) | 지금은 로컬 전용으로 확정. 바뀌면 이 문서와 §5를 함께 갱신 |
