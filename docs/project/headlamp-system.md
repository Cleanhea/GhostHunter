## 2. 헤드라이트

### 2.1 효과와 사용 방법

- 인벤토리·퀵슬롯에 넣는 아이템이 **아니다.** 플레이어 캐릭터에 기본으로 달린 종속 장비다.
- 한 번 켜면 끄기 입력이 들어오기 전까지 켜져 있다.
- **F키**로 켜고 끈다.
- 스폰할 때는 꺼져 있다 → §6.

### 2.2 배터리

| 규칙 | 값 |
| --- | --- |
| 총량 | 100 |
| 켜진 동안 감소 | 초당 0.6 (가득 찬 배터리로 약 167초) |
| 저전력 경고 | 15 이하에서 5초마다 3번 깜빡임 |
| 0 도달 | 자동으로 꺼지고, 충전 전까지 켤 수 없다 |
| 충전 | 드릴카 내부에서 초당 5 |

### 2.3 조명 범위 — 레퍼런스 크라임씬 클리너

- 플레이어 전방을 비추는 원뿔형 조명(Spot Light). 시점·카메라 방향을 따라 회전한다.
- 바닥 기준 주요 범위는 전방 약 1.5m 반경. 중심이 밝고 바깥으로 갈수록 어두워진다.
- 벽·오브젝트에 가려 그림자가 생긴다.
- 표면에는 손전등처럼 밝은 핫스팟과 흐린 주변광이 맺히고, 공기 중에는 빛줄기가 은은하게 보인다. 다른 플레이어의 빛줄기는 잘 보이고
  자기 빛줄기는 더 약하다(사용자 요청 2026-10-03, 구현 [headlamp.md §4.1](../architecture/headlamp.md)).
- 정확한 거리·각도는 실제 플레이 화면을 보고 조정한다(설정 에셋 `HeadlampSettings_Default`).

## 3. 배터리 충전 UI

- 드릴카 안에서 충전되는 동안 화면에 충전 UI를 띄운다.
- 두더지 스킬 UI와 같은 크기·색. `nn%` 형식으로 현재 배터리를 표시한다.
- 아이콘 `flashlights.png`는 아직 저장소에 없다 — 들어오면 `HeadlampChargeHud._icon`에 넣는다.

## 4. 효과음

| 상황 | 파일 |
| --- | --- |
| F키로 켤 때 | `SFX_flashlight_on.mp3` |
| F키로 끌 때 | `SFX_flashlight_off.mp3` |
| 배터리 0에서 켜려고 할 때 | `SFX_flashlight_broken.mp3` |

세 파일은 아직 저장소에 없다. 들어오면 `HeadlampSettings_Default`의 `_onClip`·`_offClip`·`_brokenClip`에 넣는다(비어 있으면 무음).

## 6. 원문에 없어 구현에서 정한 것 [임시 — 플레이 테스트로 확정]

| 항목 | 구현 | 비고 |
| --- | --- | --- |
| 시작 상태 | 스폰 시 꺼짐, 배터리 100 | 플레이어는 씬마다 재스폰되므로 스테이지마다 100으로 시작한다 |
| 감소 범위 | 스테이지 씬(`SceneId.IsStage()`)에서만 준다 | 인게임 로비에는 드릴카가 없어 충전할 수 없다 |
| 드릴카 안에서 켜 둔 경우 | 줄지 않고 충전만 된다 | |
| 자동 꺼짐 효과음 | 없음 | 원문은 F키 입력 시 효과음만 정의 |
| 효과음 청취 범위 | 누른 플레이어 본인만(2D) | 다른 플레이어에게 들릴지 미정 |
| 깜빡임 모양 | 한 번에 0.08초 꺼짐 + 0.1초 켜짐, 저전력 진입 즉시 첫 묶음 | |
| 충전 UI 표시 조건 | 드릴카 안에 있는 동안(100%가 돼도 유지) | |
| 충전 UI 위치 | 우측 상단, 탐지·굴착 게이지 아래 세 번째 칸 | |
| 은신 중 | 들어가면 자동으로 꺼지고, 그 안에서는 F키가 무시된다 | 은신 = 은신처 상자 안, 또는 엎드려 침대 밑 공간 안 |
| 사망 시 | 자동으로 꺼진다 | |
| 굴착·퀵슬롯 휠 중 입력 | F키가 살아 있다 | 땅굴 안 규칙 때문에 굴착 중에 켤 수 있어야 한다 |
| 다른 플레이어에게 보이는가 | 보인다 — 원격 플레이어 머리에서 그 사람의 시선 방향으로 비춘다 | |
