## 2. 헤드라이트

### 2.1 효과와 사용 방법

- 인벤토리·퀵슬롯에 넣는 아이템이 **아니다.** 플레이어 캐릭터에 기본으로 달린 종속 장비다.
- 한 번 켜면 끄기 입력이 들어오기 전까지 켜져 있다.
- **F키**로 켜고 끈다.
- 스폰할 때는 꺼져 있다 → §6.

### 2.2 배터리

| 규칙 | 값 |
| --- | --- |
| 총량 | 100 |
| 켜진 동안 감소 | 초당 0.3 (가득 찬 배터리로 약 333초) — 2026-10-29 사용자 결정, 이전 0.6 |
| 저전력 경고 | 15 이하에서 5초마다 3번 깜빡임 |
| 0 도달 | 자동으로 꺼지고, 충전 전까지 켤 수 없다 |
| 충전 | **배터리 팩에 E 홀드**(§8) — 기본 초당 10%p, 연속 홀드 1초마다 +5, 최대 30. 드릴카 안에 서 있다고 저절로 차지 않는다(2026-10-29, 이전: 드릴카 내부에서 초당 5 자동 충전) |

### 2.3 조명 범위 — 레퍼런스 크라임씬 클리너

- 플레이어 전방을 비추는 원뿔형 조명(Spot Light). 시점·카메라 방향을 따라 회전한다.
- 바닥 기준 주요 범위는 전방 약 1.5m 반경. 중심이 밝고 바깥으로 갈수록 어두워진다.
- 벽·오브젝트에 가려 그림자가 생긴다.
- 표면에는 손전등처럼 밝은 핫스팟과 흐린 주변광이 맺히고, 공기 중에는 빛줄기가 은은하게 보인다. 다른 플레이어의 빛줄기는 잘 보이고
  자기 빛줄기는 더 약하다(사용자 요청 2026-10-03, 구현 [headlamp.md §4.1](../architecture/headlamp.md)).
- 정확한 거리·각도는 실제 플레이 화면을 보고 조정한다(설정 에셋 `HeadlampSettings_Default`).

## 3. 배터리 충전 UI

- **배터리 팩에서 충전을 받는 동안만** 현재 배터리를 실시간으로 띄운다. E를 떼거나 가득 차거나 팩이 비면 사라진다
  (2026-10-29 — 이전: 드릴카 안에서 충전되는 동안. 사용자 결정 2026-10-29 로 "켜져 있는 동안"에서 원문으로 되돌린 표시 규칙은 그대로다).
- 두더지 스킬 UI와 같은 크기·색. `nn%` 형식으로 현재 배터리를 표시한다.
- 원 안 배치는 목업 `Assets/Sprite/Skill_icon/ICON_HeadLight.png`를 따른다 — 위에 `nn%`, 아래에 손전등 아이콘.
- 아이콘은 탐지·굴착과 같은 규격(512px 투명 선화)의 `ICON_HeadLight_on.png`(초록)·`ICON_HeadLight_off.png`(흰색)이다.
  충전 중에 헤드라이트가 켜져 있으면 링·글자·아이콘이 초록, 꺼져 있으면 흰색 → §6.

## 8. 배터리 팩 (2026-10-29, 사용자 요청 — 원문 「4. 배터리 팩」)

### 8.1 규칙 [원문]

- 손전등의 배터리를 충전할 수 있는 오브젝트다.
- 해당 오브젝트에 **E키를 홀드**하면 손전등의 배터리를 충전할 수 있다.
  - 기본 충전 속도는 **초당 10%p**다.
  - E키를 연속으로 홀드하면 **1초마다 초당 충전량이 5%p씩 증가**하며, 최대 **초당 30%p**까지 증가한다.
  - 손전등 배터리가 100%에 도달하면 충전이 자동으로 종료된다.
- E키 홀드를 해제하면 충전이 종료된다. 충전을 종료하면 충전 속도가 초기화되며, 다시 충전할 때는 기본 충전 속도로 시작한다.
- 배터리 팩의 표시된 배터리 잔량은 **모든 플레이어가 공유**하는 양으로, **잔량이 0%가 되면** 배터리 팩에 상호작용하거나 손전등 배터리를 충전할 수 없다.

### 8.2 충전 속도

| 연속 홀드 시간 | 초당 충전량 |
| --- | --- |
| 0 ~ 1초 미만 | 10%p |
| 1 ~ 2초 | 15%p |
| 2 ~ 3초 | 20%p |
| 3 ~ 4초 | 25%p |
| 4초 이상 | 30%p (상한) |

- 홀드가 끊기는 조건: E를 뗌 · 배터리 팩에서 시선이 벗어남 · 헤드라이트 가득 참 · 팩 잔량 0 · 사망·일시정지·굴착·퀵슬롯 휠 등 입력 잠금. 끊기면 속도는 처음(10%p)으로 돌아간다.
- 5초를 쭉 홀드하면 10+15+20+25+30 = **100%p** — 빈 배터리를 가득 채우는 데 약 5초가 걸린다.
