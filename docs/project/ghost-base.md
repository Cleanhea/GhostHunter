## 2. 개요

### 2.1 베이스 귀신이란 [확정 — 원문]

공통 기획서의 시스템(상태·정신력 연동·어택·탐지·추격·수색)에 **'뒤돌아보지마' 기믹**이 적용된 귀신이다.
튜토리얼에 쓰는 귀신이다.

> **이전 정의 대체.** 공통 기획서 §3.4는 베이직 귀신을 "고유 능력·특수 조건·특수 탐지가 하나도 없는 귀신"으로
> 적었다. 원문이 기믹을 붙이면서 이 정의는 대체됐다. 튜토리얼 밖의 귀신 종류는 정해지지 않았다 → BG-10.

### 2.2 공통 규칙과의 관계

| 공통 규칙 | 베이스 귀신 |
| --- | --- |
| 활동·경고·자연 진정 (공통 §4.4·4.5·4.7) | **변경 없음.** 기믹은 어택 중에만 동작한다 |
| 어택 중 이동 (공통 §9) | **덮어씀** — 시선에 따른 정지·면역·가속 (§3.2) |
| 공격(포획) 조건 | **덮어씀** — 거리 구간별 시선 조건 (§3.4). 공통 기획서는 포획 사거리를 정하지 않았다 |
| 본체 노출 (공통 §3.3·§10.4) | **변경 없음.** 본체는 어택에만 보이므로 정지시킬 대상이 바로 눈에 보인다. 어둠에서의 가시성은 BG-1 |
| 탐지·추격·수색·은신 (공통 §8·§9) | **변경 없음** |

## 3. 뒤돌아보지마 기믹

### 3.1 개요 [확정 — 원문]

- 어택 중 플레이어가 귀신을 바라보면 귀신이 석고상처럼 굳어 이동을 멈춘다.
- 여러 플레이어 중 **한 명이라도** 귀신을 바라보면 정지한다.
- 레퍼런스 영상: https://www.youtube.com/shorts/l_kwhj2WS08

### 3.2 이동 및 정지 규칙 [확정 — 원문]

| 조건 | 귀신 행동 |
| --- | --- |
| 플레이어가 귀신을 바라봄 | 즉시 정지 (최대 5초) |
| 아무도 귀신을 바라보지 않음 | 즉시 이동 재개 |
| 정지 후 5초 경과 | 강제 이동 재개 |
| 정지 해제 후 5초간 | 정지 면역 (기믹 발동 불가) |
| 면역 종료 후 | 다시 정지 가능 |

- **이동 속도:** 정지 해제 후 기존 이동 속도의 **1.5배**로 이동한다.
- **가속 종료:** 플레이어가 다시 귀신을 정지시키거나 5초가 경과하면 기존 속도로 돌아온다.
- **정지 면역:** 정지 해제 후 5초간 시야에 의한 정지가 불가능하다.

> 면역과 가속이 둘 다 "해제 후 5초"라서, "다시 정지시키면 가속 종료" 조항은 면역이 끝나는 시점(=가속도 5초가 차는
> 시점)과 겹쳐 따로 발동할 일이 없다. 의도된 중복인지 확인이 필요하다 → BG-4.

### 3.3 상태 흐름

```text
이동 ── 누군가 바라봄 (면역 아닐 때) ──▶ 정지 (최대 5초)
                                           │
   아무도 안 바라봄 ── 즉시 ────────────────┤
   정지 5초 경과 ──── 강제 ────────────────┤
   0.8m 이하 플레이어 ─ 해제 후 즉시 공격 ──┘  (이 경우 면역·가속은 BG-6)
                                           ▼
                        해제 후 5초: 정지 면역 + 이동 ×1.5
                                           ▼
                        5초 경과 → 기존 속도, 다시 정지 가능
```

기믹은 **어택 상태에서만** 동작한다. 활동·경고·자연 진정에서는 귀신이 평소대로 움직인다.

### 3.4 공격 규칙 [확정 — 원문]

| 귀신과 플레이어의 수평거리 | 공격 조건 |
| --- | --- |
| 1.5m 초과 | 공격 불가 |
| 0.8m 초과 ~ 1.5m 이하 | 귀신을 **바라보지 않는** 플레이어만 공격 가능 |
| 0.8m 이하 | 시야와 관계없이 공격 가능 |

- **정지 중에는 공격을 시작하지 않는다.** 단, 0.8m 이하에서는 정지를 해제하고 즉시 공격한다.
- 이미 시작한 공격은 시야 판정으로 중단되지 않는다.
- 공격 방식은 기존 귀신 공격 규칙을 따른다 (잡히면 사망 → [death-system.md](death-system.md)).
- 수평거리는 높이(Y) 차이를 뺀 거리다.

> **0.8~1.5m 구간이 실제로 가르는 경우.** 누가 바라보면 귀신이 정지해 공격을 시작하지 않으므로, 이 구간의 시선 조건이
> 의미를 갖는 때는 **정지 면역 중**(바라봐도 정지하지 않음)에 일부 플레이어만 바라보고 있을 때다. 규칙에서
> 따라 나오는 결과이며 새 규칙이 아니다.

### 3.5 수치 요약 (초기값 — 최종 권위는 SO 설정 에셋)

| 항목 | 값 |
| --- | --- |
| 정지 최대 시간 | 5초 |
| 정지 면역 | 해제 후 5초 |
| 가속 | 기존 이동 속도 ×1.5, 해제 후 5초 (종료 조건 BG-4) |
| 공격 불가 거리 | 수평 1.5m 초과 |
| 시선 무관 공격 거리 | 수평 0.8m 이하 |

## 4. 설계 맥락 (원문 보조표)

원문이 베이직 귀신 기믹과 함께 적은 설계 정리다. 표는 **"1스테이지"** 기준으로 적혀 있다 — Tutorial인지
Stage1인지는 BG-10에서 확인한다.

| 항목 | 내용 |
| --- | --- |
| 행동 목록 | 가구 잡기·운반 / 던지기·충돌 내구도 관리 / 상호작용 재물 탐색·절도 / 대걸레 얼룩 닦기 / 드라이버로 가구 축소 / 탐지·굴착 스킬 / 플레이어끼리 밀치기 / 손전등 배터리 / 정신력 / 귀신 회피·대응으로 목숨 관리 |
| 학습 목표 | 가구 운반 조작 · 내구도 관리 · 재물 탐색·절도 · 대걸레 · 드라이버 축소 · **귀신의 어택 예고를 알아차린다 · 운반 중인 가구를 내려놓고 회피한다 · 굴착이나 은신으로 추격에서 벗어난다** |
| 귀신이 개입하는 순간 | 집 안에 플레이어가 체류 중일 때(작업 중 / 단순 체류), 귀신의 어택타임 |
| 개입으로 생기는 문제 | 작업 중: 방해로 인한 손실(가구 내구도, 재물 파손으로 인한 보상 손실)·작업 시간 증가 / 단순 체류: 이동 방해·정신력 감소로 작업 지연 / 어택타임: 잡히면 사망 |
| 대응 방법 | 굴착 스킬(빠른 이동·숨기) / 가구 밑 등 숨을 수 있는 스팟에서 웅크리고 손전등을 꺼서 은신 / 달리기로 도망 / 귀신의 기믹에 따라 대응법 추가 가능 (베이스 귀신: 바라봐서 정지시키기) |
| 전달 방법 | 어택타임이 시작되면 전등이 깜빡임 / 어택타임에 귀신 외형이 실체화되어 보임 / 어택타임에 귀신 시야가 붉은 원뿔 빛으로 표현됨 |

> **공통 기획서와 맞춰 읽기.** 전등 깜빡임은 공통 기획서의 경고 5초(§10.3), 붉은 조명은 어택(§10.4)과 같은 연출이다.
> 붉은 원뿔 시야 표시는 공통 기획서에서 과거 저장소판 규칙으로 분류돼 유지 여부가 미결정이다(G-21). 이 표는 베이스 귀신의
> 어택 신호로 그것을 적었다.
>
> 뒤돌아보지마의 **정지·면역 상태를 플레이어에게 알리는 단서**는 이 표에 없다 → BG-3.

## 5. 후속 귀신 아이디어 (미채택)

원문의 같은 문서에 있던 **'아이디어 1. 강제 순간이동 귀신'** 이다. 베이스 귀신의 규칙이 아니며 채택되지 않았다.

- 특정 조건(예: 집 안에 모든 플레이어가 체류 중)이 충족되면 랜덤한 플레이어를 집 안 랜덤한 위치로 강제 이동시킨다.
- 한 번 이동한 뒤 1분 쿨타임을 가진다. 어택 시에는 특별한 기믹이 없다.
- 원문의 기믹 문장 틀("플레이어가 ___하는 상황에서 귀신이 ___라는 예고를 보낸다 …")은 빈칸으로 남아 있다.

**기믹 평가 기준 (원문):** 규칙을 이해하면 대응을 계획할 수 있어야 한다(위치·운반 중인 가구·팀원 배치에 따라 판단이 달라지고,
대응에 성공하면 작업 기회가 생긴다). 점검 항목은 ① 알아챌 수 있는가 ② 행동으로 대응할 수 있는가, 성공 이유를 이해하는가
③ 실수하고 배울 수 있는가(첫 실수가 바로 사망이나 긴 재작업으로 이어지지 않는가).

| BG-4 | **면역과 가속의 길이.** 둘 다 해제 후 5초라 "다시 정지시키면 가속 종료"가 따로 발동하지 않는다. 의도된 중복인지, 두 시간이 다를 의도인지 | 가속 종료 조건 |
| BG-5 | **×1.5가 곱해지는 "기존 이동 속도".** 어택 중 추격·수색·배회가 모두 `ChaseSpeed` 3.4 m/s라 구현은 전부에 곱한다(임시 해석) — 확인 필요 | 가속 튜닝 |
| BG-6 | **해제 사유별 면역·가속.** 구현은 세 사유(시선 이탈 / 5초 경과 / 0.8m 이하 근접) 모두 면역·가속을 준다(임시 해석) — 확인 필요 | 정지 상태 기계 |
| BG-7 | **"이미 시작한 공격"의 정의.** 포획이 접촉 즉시 사망이라 시작·완료 구간이 없어 구현은 해당 없음으로 뒀다. 기믹이 켜진 귀신은 `CatchRadius` 1.4m 대신 1.5m 상한을 쓴다. 선딜 모션을 넣으면 다시 정해야 한다 | 공격 모션 |
| BG-8 | **적용 범위.** 구현은 어택 하위 행동 전부에서 정지하고 어택을 벗어나면 초기화한다(임시 해석). 호스트 이전 스냅샷 복원은 미구현 | 호스트 이전 복원 |
| BG-9 | **정식 이름.** 현재 "베이스 귀신"은 임시, 원문 제목은 "베이직 귀신" | 문서·에셋 이름 |
