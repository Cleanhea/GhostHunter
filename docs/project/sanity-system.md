## 2. 개요

### 2.1 문서 목적과 범위

이 문서는 게임 스테이지에서 활성화되는 **정신력 시스템**의 정의와 기본 규칙을 설명한다.

- 개인 정신력의 역할과 생명주기
- 팀 평균 정신력 산정 방식
- 정신력 증가·감소 조건(감소: 귀신·시체 목격 / 증가: 아이템·귀중품·돈 발견)
- 정신력 수치를 전달하는 UI와 시청각 피드백

다음 내용은 이 문서의 범위가 아니다.

- 정신력 상태에 따른 귀신의 구체적인 행동·이벤트
- 정신력 증가 아이템별 사용법·증가량·지속 시간
- 헤드라이트 시스템의 전체 사양

귀신 행동은 [ghost-system.md](ghost-system.md), 현재 P1 구현은
[ghost-prototype.md](../architecture/ghost-prototype.md), 헤드라이트는 [headlamp-system.md](headlamp-system.md),
아이템의 상세 규칙은 향후 전용 문서에서 정의한다.

저장소 Markdown에서는 원문의 초록색 기획 의도 표시를 `> **기획 의도**` 인용 블록으로 표현한다.

### 2.2 시스템 개요

- 정신력은 플레이어 캐릭터의 **정신적 안정도**를 나타내는 수치다.
- 정신력은 스테이지를 시작할 때 기본값으로 초기화되고 스테이지가 종료되면 비활성화된다.
- 각 생존 플레이어는 개인 정신력을 가진다.
- 생존 플레이어들의 개인 정신력 평균을 **팀 평균 정신력**으로 사용한다.
- 팀 평균 정신력은 귀신의 공격과 이벤트 발생 조건이 되는 핵심 값이다.
- 개인 정신력이 낮아지면 카메라 테두리 노이즈와 SFX 등 시청각 디버프가 중첩 적용된다.
- Game 플레이 중에는 씬 후면의 World Space 정신력 모니터에서 최대 4인의 개인 정신력과 팀 평균 정신력을 확인할 수 있다.
- Stage1에서는 이 모니터를 **드릴 카 실내 앞벽**에 둔다. 원문의 "드릴 카 내부 모니터"는 별도 화면이 아니라 이 모니터다(§6.2).

> **기획 의도**  
> 개인뿐 아니라 팀 전체의 정신력을 관리하게 하여 협동을 유도한다. 정신력으로 귀신의 공격을
> 예측·대비할 수 있게 해 통제감을 제공하고, 안전과 작업 수익성 사이의 판단을 만든다.
> 반복적인 가구 이동·청소 작업에도 정신력 관리를 결합해 긴장감과 전략성을 높인다.

## 3. 정신력 데이터

### 3.1 개인 정신력

| 항목 | 규칙 |
| --- | --- |
| 소유 단위 | 플레이어 개인 |
| 값 범위 | 0~100의 정수 |
| 단위 | 퍼센트(%) |
| 활성 구간 | 스테이지 진행 중 |
| 사망 플레이어 | 정신력 값을 제거하고 UI에는 `-%` 표시 |
| 연결 종료 플레이어 | 스테이지에서 제거하며 정신력 값도 제거 |
| 상태 확인 | World Space 정신력 모니터의 P1~P4 고정 슬롯 |
| 정확한 수치 확인 | 각 플레이어 슬롯의 정수 퍼센트 표기 |

스테이지 시작 시 개인 정신력은 **100%**로 초기화한다.

World Space 정신력 모니터는 현재 게임에 접속한 모든 플레이어의 개인 정신력을 P1~P4 슬롯에
정수 퍼센트로 표시한다. 아래 임계값에 따른 시청각 디버프도 함께 제공한다.

### 3.2 팀 평균 정신력

팀 평균 정신력은 **생존 중인 모든 플레이어의 개인 정신력 산술 평균**이다.

```text
팀 평균 정신력(실수) = 생존 플레이어 개인 정신력 합계 / 생존 플레이어 수
팀 평균 정신력(판정값) = 실수 평균을 소수점 아래 첫째 자리에서 반올림한 정수
```

| 항목 | 규칙 |
| --- | --- |
| 원본 값 | 0~100의 실수 |
| UI·귀신 판정값 | 반올림한 0~100의 정수 |
| 포함 대상 | 생존 중이고 현재 연결된 플레이어 |
| 제외 대상 | 사망했거나 연결이 종료된 플레이어 |
| 상태 확인 | World Space 정신력 모니터의 팀 행 |
| 정확한 수치 확인 | 팀 행의 반올림된 정수 퍼센트 표기 |

World Space 정신력 모니터는 반올림한 팀 평균 정신력을 팀 행의 정수 퍼센트로 표시한다.
생존 인원은 표시하지 않는다.

> **예외 처리 TBD:** 생존 플레이어가 0명일 때 팀 평균 값을 계산하지 않는 것은 확정이나,
> 내부 표현값과 UI 표시 방식은 승패·전멸 규칙과 함께 결정한다.

## 4. 개인 정신력의 증가·감소

### 4.1 증가

개인 정신력은 아래 두 경우에 **즉시** 증가한다.

1. **정신력 증가 아이템 사용** — 아이템별 사용 방식, 증가량, 지속 시간은 각 아이템 문서에서 정의한다.
2. **귀중품·돈 발견** (원문 0.4, 사용자 확정 2026-10-29) — 발견한 **그 플레이어**의 정신력이 즉시 오른다.
   증가량은 발견 금액($)에 따른다.

| 발견 금액 | 정신력 증가량 |
| ---: | ---: |
| $2 | +3 |
| $3 | +5 |
| $5 | +10 |
| $10 | +15 |

> **구현 범위:** 증가 API(`SanityNetworkState.ServerApplyValuableFound(int dollars)`)와 금액별 증가표(설정 에셋)만
> 구현했다. **귀중품·돈 획득 시스템 자체는 추후 구현**이라 호출부가 아직 없다.
> 위 표가 **전체 금액 체계**다(사용자 확정 2026-10-29). 표에 없는 금액은 증가하지 않는다.
> 증가는 **획득한 개인에게만** 적용한다(공동 잔액과 별개, 사용자 확정).

### 4.2 감소

| 감소 조건 | 방식 | 감소량 | 예외·중복 방지 |
| --- | --- | ---: | --- |
| 귀신 이벤트 목격 | 즉시 감소 | **5** (2026-10-29: 15 → 5) | 이벤트별 중복 판정 규칙은 귀신 이벤트 문서에서 정의 |
| 활동 중 귀신 본체 목격 | 최초 목격 및 지속 감소 | 최초 5, 계속 보고 있으면 5초마다 5 | 본체 노출·목격 기준과 귀신 이벤트 −5와 **같은 프레임에 둘 다 보면 −5가 각각 적용(합 −10)** — 의도된 규칙(사용자 확정 2026-10-29). 본체 목격 판정 기준(거리·각도·가림)만 [G-17](ghost-system.md#13-미결정-목록) 대기 |
| 동료 플레이어의 시체 목격 | 즉시 감소 | **10** (2026-10-29: 20 → 10) | 최초 목격에만 감소. 같은 시체를 다시 목격해도 추가 감소하지 않음 |

모든 증감 결과는 0~100 범위로 제한한다.
활동 중 귀신 본체 목격은 서버의 `SanityNetworkState.ServerApplyGhostBodyWitnessed()`로
연결했다(2026-09-27). 현재 목격 판정은 12m/70°·가림을 임시로 재사용하며 G-17에 남긴다.

### 4.3 어둠 노출 — 정신력 감소 삭제 (2026-10-29)

이전에는 헤드라이트(·라이터)가 꺼진 채 드릴 카 밖에 있으면 누적 10초마다 정신력을 1 깎았다.
원문 0.4가 어둠 노출의 감소 값을 `-`로 바꿔 **사용자가 삭제를 확정했다.**

- 어둠 노출·누적 타이머·`SanityNetworkState.ServerSetDarknessExposed` 등 **판정 체인 전체를 코드에서 제거했다.**
- 헤드라이트·라이터는 그대로 남는다. 이제 정신력과 무관하게 **시야 확보**와 **땅굴 은신 판정**
  ([mole-skill-system.md §5.2.1 ②](mole-skill-system.md))에만 쓰인다.
- **헤드라이트의 존재 이유는 "맵이 어두우니 밝게 보기 위한 것"이다**(사용자 확정 2026-10-29). 배터리·충전·저전력 깜빡임 등
  [headlamp-system.md](headlamp-system.md)의 규칙은 그대로 둔다.

## 5. 개인 정신력 디버프

`n`을 현재 개인 정신력 정수값이라고 한다.

| 발동 조건 | 효과 | 종료·재발동 규칙 |
| --- | --- | --- |
| `n ≤ 20` | 카메라 테두리 노이즈 | `n > 20` 또는 사망 시 종료 |
| `n ≤ 10` | 속삭임 SFX를 3~10초 중 무작위 간격으로 반복 재생 | `n > 10` 또는 사망 시 종료 |
| `n ≤ 5` | 숨소리 + 심장 소리 SFX 1회 재생 | 1회 재생 후 종료. 조건을 벗어났다가 다시 충족하면 재생 가능 |

- 여러 발동 조건을 동시에 충족하면 **모든 효과를 중첩 적용**한다.
- `n ≤ 5`이면 카메라 노이즈와 속삭임 반복이 유지되며 숨소리·심장 소리가 1회 추가 재생된다.
- 플레이어가 조건을 벗어났다가 다시 충족하면 해당 디버프를 다시 활성화한다.

## 6. 정신력 UI

### 6.1 Game World Space 정신력 모니터

Game 씬 후면에는 레퍼런스의 트럭 정신력 화면을 기반으로 한 **World Space 정신력 모니터**를
배치한다. 화면에 고정되는 HUD가 아니며 플레이어 카메라로 월드 안의 모니터를 직접 바라봐야 한다.

| 항목 | 규칙 |
| --- | --- |
| Canvas | World Space, 960×540 기준 |
| 배치 | Game 프로토타입 공간 후면, 집 뒤쪽에서 전면을 향하도록 배치 |
| 화면 스타일 | 검은 화면, 옅은 청색 프레임·제목선, 붉은 상태 심볼·정수 퍼센트. 게이지는 사용하지 않음 |
| 개인 슬롯 | P1~P4 고정 4슬롯. 접속 플레이어를 Client ID 오름차순으로 배치하고 각자의 `0%`~`100%` 정수 표기 |
| 미접속 슬롯 | 슬롯은 제거하지 않고 라벨·심볼·`-%`를 흑백 비활성 색상으로 표시 |
| 사망 플레이어 | 접속 슬롯은 유지하고 개인 수치는 `-%`로 표시 |
| 팀 행 | 생존 플레이어 팀 평균을 반올림한 `0%`~`100%` 정수 표기 |
| 생존자 0명 | 팀 행을 흑백 비활성 색상과 `-%`로 표시 |

모든 클라이언트는 복제된 플레이어 상태를 집계하여 같은 P1~P4 개인 수치와 팀 평균을 표시해야 한다.

### 6.2 드릴 카 모니터 = 월드 P1~P4 슬롯 모니터 [확정 — 2026-10-29]

원문 0.4는 "드릴 카 내부 모니터에 생존 중인 모든 플레이어의 개인 정신력과 팀 평균을 정수로 표기"하고,
연결이 끊긴 플레이어는 목록에서 삭제하라고 적었다. **사용자 확정으로 별도의 목록형 상세 모니터를 만들지 않고,
위 월드 P1~P4 슬롯 모니터를 정식 드릴 카 모니터로 쓴다.** 레퍼런스는 Phasmophobia의 트럭 정신력 모니터다.

| 원문 0.4 | 이 저장소의 확정 |
| --- | --- |
| 생존·사망 플레이어 개인 수치, 팀 평균을 0~100 정수로 표기 | §6.1 그대로 — 개인 `0%`~`100%`, 사망 `-%`, 팀 평균 반올림 정수 |
| 연결이 끊긴 플레이어의 행을 목록에서 삭제 | **삭제하지 않는다.** 고정 4슬롯을 유지하고 흑백 `-%`로 표시한다(§6.1) |
| 드릴 카 내부에 설치 | Stage1은 드릴 카 실내 앞벽([stage-system.md §2.1](stage-system.md)). ProtoTypeGame·Tutorial은 각 씬 저장값을 따른다 |

별도 상세 목록 UI(정렬·갱신 애니메이션·상호작용)는 **만들지 않는다.** 필요해지면 새로 결정한다.

**원문 §4-1 레퍼런스 이미지** (Phasmophobia 트럭 정신력 화면, 사용자 제공 2026-10-29) — `docs/images/sanity-monitor-reference.png`:

![Phasmophobia 정신력 모니터 레퍼런스](../images/sanity-monitor-reference.png)

상단 제목 "팀 정신력" 밑줄, 2×2 슬롯(붉은 머리 아이콘 + 퍼센트), 값을 알 수 없는 슬롯은 `?`로 표시한다. 구현은 이 구성을 참고하되
제목·슬롯 수·`-%` 표기는 §6.1을 따른다(레퍼런스의 이름 라벨·`?` 표기는 채택하지 않았다).

**원문 §4-2 "개인 정신력 수치 별 디버프 연출"은 내용이 없다**(사용자 확인 2026-10-29). 추가 연출은 없으며 디버프는 §5의 세 가지(노이즈·속삭임·숨·심장)가 전부다.

개인 정신력, 생존자 팀 평균, 감소·회복 API, 시체 중복 방지, 디버프 상태와 Game 정신력 모니터는
P1으로 구현했다.
구조와 검증 결과는 [sanity-system.md](../architecture/sanity-system.md)를 따른다.

개인 디버프 중 **카메라 테두리 노이즈(`n ≤ 20`)는 구현했다.** 속삭임과 숨·심장 소리는 오디오
에셋이 나오면 붙인다. 감소 조건을 실제로 걸어 볼 수 있도록 집 서쪽에 임시 테스트 공간(시체 2구,
귀신 이벤트 1개)을 두었다 — 정식 시체·이벤트 시스템이 생기면 삭제한다.

귀신 P1이 따로 만들던 팀 공용 모의 정신력은 **제거했다.** 이제 정신력 수치의 출처는 이 시스템
하나뿐이며, 귀신 F1 HUD는 `ISanityTeamService`가 집계한 팀 평균 판정값을 그대로 표시한다.
귀신 코드의 팀 평균 연동은 구현됐지만 **과거 구간(80 이하 활동 / 60 이하 어택 판정 /
30 이하 고위험 표시)**을 따른다. 현행 원문 0.2의 활동 시작·0~30 강제 어택 등은
[귀신 시스템 기획서 §12.3](ghost-system.md#123-현재-구현과의-차이)과 roadmap `M8-GS-1c`에 남아 있다.
