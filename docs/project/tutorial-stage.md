# Tutorial 스테이지 — 원룸

## 확정된 범위

- Tutorial의 **202호 한 방**이 작업 구역이다. 맵 이름 원룸, 2~4명, 쉬움.
- 1m = 원본 도면 100px. Unity에서는 1 unit = 1m이며 모든 작성한 맵·Tutorial 가구 Transform의 localScale은 1이다.
- 목표 플레이 시간 5~8분, 10분 이내는 설계 목표다. 시간 제한에 따른 강제 종료·탈락은 없다. 실제 다인 플레이 시간과 난이도 평가는 필요하다.
- 베이직 귀신 1명. 매 판 초자연현상 **3종류**를 선택해 반복하며 직전 종류는 연속 선택하지 않는다.
- 첫 게임: 일반 Lobby 또는 Local Host → InGameLobby(드릴카 상점) → 출발 → Tutorial. 드릴카 종료나 팀 전멸 → Result → InGameLobby → 다음 출발 Stage1.
- 정산 없이 ESC로 나가면 Tutorial을 다시 시작한다. Title/일반 Lobby로 돌아가면 첫 스테이지 기록을 초기화한다. 완료 기록을 디스크에 저장하지 않는다.
- Stage1 밤·안개·StageLightingSettings_Default를 참조한다. 드릴카는 모텔 앞에 배치한다.

Tutorial의 도면 얼룩은 이동 가구에 가려졌다는 이유로 누락하지 않는다. 고정된 바닥을 기준으로 배치하고, 가려진 얼룩은 가구를 옮긴 뒤 닦는다.

TV/선반을 포함한 가구별 가격표는 미정이다. 현재 정산·상점 보상은 기존 스테이지 규칙을 사용하며 새 가구 가격/보상 수치를 만들지 않았다.

## 안내와 퀘스트

**2026-10-03 사용자 변경 — 상시 패널 대신 가운데 카드 연출.** TutorialHud 는 단계가 바뀔 때 화면 가운데에 카드를 띄우고(페이드·살짝 커지며 등장),
플레이어가 **[X]** 로 닫는다(커서가 잠겨 있어 클릭이 아니라 키, Enter 는 공격 키라 쓰지 않는다). 처음엔 **기본 조작 카드**(키캡 8개)가 뜨고, 닫으면 지금 단계 카드가 뜬다.
닫은 카드는 다시 뜨지 않는다. 카드가 떠 있는 동안 팀이 다음 단계로 넘어가면 새 단계 카드로 바뀐다. 카드는 입력을 막지 않고, ESC 메뉴가 열린 동안 숨는다.
진행 수치(얼룩·반출 개수)는 기존 청소 진행도 HUD 가 보여 준다. **이전 패널에 있던 "조준한 가구 내구도 n/100" 상시 표시와 "밀치기 연습 □/✓" 표시는 없앴다.**

1. **루시우(가구 밀치기)**: Tab으로 맨손 선택, 가구 조준, 좌클릭 홀드 후 해제. 강한 벽·바닥 충돌은 내구도를 줄인다고 안내하며 조준 가구의 현재 내구도를 표시한다.
2. **청소**: 팀의 가구 발사가 한 번 확인되면 Tab 대걸레 선택·좌클릭 청소·Q 탐지를 안내한다. 얼룩 목표 7개를 표시한다.
3. **반출**: 얼룩을 모두 닦으면 2인 좌클릭 홀드 운반·휠 회전·휠 클릭 기울이기 전환·드릴카 운반을 안내한다. 반출 목표 6개를 표시한다.
4. **목표 완료**: 얼룩 7개와 가구 6개를 마치면 드릴카의 E 종료 버튼과 정산 후 Stage1 출발을 안내한다.

단축키: WASD 이동, Shift 달리기, Space 점프, E 상호작용, F 헤드램프, Tab 도구 선택, Q 탐지, Esc 메뉴.
안내 순서와 별개로 청소·반출은 언제든 진행할 수 있다. 퀘스트가 완료되어도 자동 정산하지 않는다.
기존 종료 버튼과 팀 전멸 처리, 두 작업의 별도 집계 기준을 사용한다. 새로운 합산 진행도나 승패 수치는 정의하지 않는다.

## 방 치수

입구에서 방 안을 바라보는 도면 방향: 왼쪽 TV/탁상·책상·의자, 오른쪽 뒤 침대/탁자, 오른쪽 앞 화장실.

| 요소 | 치수·배치 |
| --- | --- |
| 바닥 | 7.4 × 7.12m, Y 3.57. 기존 폭 7.365m에서 도면 치수에 맞춰 3.5cm 확장 |
| 침대 | 3.5 × 1.5 × 1.3m, 오른쪽 뒤 |
| 책상 | 길이 3 × 폭 1 × 높이 0.8m, 왼쪽 벽. 전화기·메모는 책상 중앙에 놓고 함께 움직임 |
| 의자 | 약 1 × 1m 평면, 기존 높이 약 1.2m |
| TV탁장 | 약 1 × 2.1 × 0.922m, 왼쪽 뒤. TV는 별도 반출 가구로 위에 놓임 |
| 침대 옆 탁자 | 1 × 1m 평면, 기존 높이 약 1.043m. 현재 고정 받침 |
| 화장실 | 외곽 3 × 3m |
| 세면대 구역 | 기구·거울 수납장·등 합계 0.8 × 0.9 × 1.9m |
| 변기 | 0.8 × 1 × 1m |
| 입구 | 왼쪽 여유 1.2m, 문 폭 1.8m, 문 구간 끝에서 침대 시작까지 0.9m |
| 선반 | 침대 왼쪽 뒤, 도면 좌표 (3.35, 6.55)m |

도면 좌표의 원점은 왼쪽 앞 모서리다. 월드 변환은 (0.475 − x, 3.57 + 높이, −0.55 − 깊이).
맵 치수·반전·축 보정과 물리 가구 메시 변환은 native Mesh에 베이크했다. 원본 FBX와 기존 GUID는 유지한다.
욕실 위치 변경 후 남아 있던 걸레받이를 외곽으로 맞췄고, 얇은 장식 걸레받이는 충돌에서 제외했다.
침대와 벽이 겹치지 않게 기존 건물의 해당 벽 안쪽 면을 보정했다. 책상/TV탁장의 접촉 오차는 책상을 입구 쪽으로 1cm 옮겨 해결했다.
발코니 윗면을 객실 높이 3.57m에 맞추고, 계단·중간 발판도 그 높이로 이어지도록 보정했다. 높은 턱이 있는 상부 계단은 저장된 경사 충돌 메시를 사용한다. 출입구에 겹친 실외기 2개와 그릴은 옆으로 1.6m 이동했다.
건물 메시의 202호 외벽(좌·뒤·앞)과 천장은 바깥 면만 있어 안에서 뚫려 있으므로, `Motel/Room202_ShellColliders` 아래 렌더러 없는 BoxCollider 7개(좌·뒤·우 벽, 문 구간 x −2.525~−0.725를 비운 앞벽 2조각·문 위, 천장)로 막았다. 보이는 안쪽 면은 `Room202/Room202_InnerWalls`(Baked/SM_Room202_InnerWalls, 맵 규약대로 같은 메시의 MeshCollider 포함)가 채운다 — 침실 벽·천장은 M_Room2F_Wall_Left, 욕실 외벽 쪽은 M_Room202_Bath_Walls 아틀라스의 민무늬 판에 UV를 맞췄고 문·Window_202 구멍은 비웠다.

원본 FBX와 NavMesh에 쓰는 모든 native 메시의 Read/Write를 켰다. 귀신이 PhysicsColliders로 런타임 NavMesh를 만들 때 원본 메시 읽기가 필요하다.
Normal은 normal map 타입, MetallicSmoothness는 Linear다. 원본 재내보내기 시 외부 재질 매핑·프리팹·Baked를 함께 검토한다.
씬/프리팹이 원본이며 지속적으로 유지하는 생성·설치 도구는 없다.

FurnitureSpawnPoint.SupportItem은 책상 위 소품과 TV탁장 위 TV의 지지 관계다. 전체 가구 경계가 겹치더라도 이 관계에 한해 배치를 허용한다.
선택 후보는 실제 서버 배치 계획으로 검증한다. 일반 가구 간 겹침 금지와 후보 중복 금지는 유지한다.
GhostPrototypeSettings_Tutorial은 물건 흔들기·소품 떨어뜨리기·조명 이상·환영 중 3종을 선택한다. 문/서랍 상호작용 모델과 음향 에셋이 없는 현상은 후보에서 제외한다.
귀신의 활동 범위는 202호 X/Z와 해당 층 높이로 제한한다.
호스트 이전 스냅샷에 선택한 현상 종류와 가구 발사 기록을 포함한다.
