## 2. 개요

### 2.1 문서 목적과 범위

이 문서는 **모든 귀신에게 공통으로 적용되는** 규칙을 정의한다.

- 귀신 생성·존재 방식
- 5개 공통 상태와 전이 조건
- 팀 평균 정신력 연동
- 초자연현상
- 어택 타임 판정·지속·종료
- 플레이어 탐지, 추격·수색 AI
- 상태별 공통 연출과 예외 처리

다음은 이 문서의 범위가 **아니다.**

| 내용 | 정의하는 곳 |
| --- | --- |

| 공통 규칙을 덮어쓰는 귀신별 예외 | 각 귀신 개별 시스템 기획서 (미작성) |

| 강제 진정 아이템의 종류·소지 개수·사용 조건 | 아이템 기획서 (미작성) |
| 두더지 땅속 은신의 쿨타임·유지시간 | [mole-skill-system.md](mole-skill-system.md) §5 (초안) |
| 현재 프로토타입 구현·배선·검증 | [ghost-prototype.md](../architecture/ghost-prototype.md) |

### 2.3 시스템 목적

귀신은 플레이어의 청소·이사 작업을 방해하고 생존 위협을 제공하는 핵심 시스템이다.
정신력·청소 진행도·귀신별 특수 조건에 따라 활동하며, 조건을 만족하면 실제로 플레이어를
공격하는 어택 상태로 진입한다.

```text
청소·이사 작업 → 귀신 활동 증가 → 위험 징후 → 어택 → 도주·은신 → 어택 종료 → 작업 재개
```

평소에는 초자연현상으로 작업을 방해하고, 특정 순간에만 직접적인 생존 위협으로 전환한다.

## 3. 귀신 생성과 존재 방식

### 3.1 생성 규칙 [확정]

- 집 하나당 기본 귀신은 **1마리** 생성한다.
- 기본 귀신은 **해당 집 내부에서만** 활동한다.
- 귀신은 집 외부와 드릴 카에 **갈 수 없다.**
- 특수 조건을 충족하면 추가 귀신이 생성될 수 있다.
  - 귀신 들린 인형 등 **저주받은 오브젝트**를 옮기려 할 때
  - 귀신별 특수 조건 충족

복수 귀신의 상태·어택 처리 규칙은 [§13 G-10](#13-미결정-목록)에서 대기 중이다.

### 3.2 존재 방식 [확정]

귀신은 **평상시에도 집 내부에 실제 위치를 가지고 이동한다.** 실제 위치는 다음에 쓰인다.

- 주변 오브젝트 간섭
- 문·환경 오브젝트 조작
- 초자연현상 발생 기준 위치
- 귀신 이동
- 어택 시 탐색 시작 위치

### 3.3 시각 노출 정책 [확정]

> **기획 의도**
> 플레이어가 귀신의 모습에 익숙해지는 것을 방지한다. 집 안에 실제로 존재한다는 공간감은
> 유지하되, 모습 자체는 아껴서 보여 준다.

귀신의 실제 모습을 **상시 노출하지 않는다.** 시각적으로 노출하는 경우는 다음뿐이다.

- 초자연현상
- 귀신별 특수 이벤트 (개별 귀신 기획서에서 정의)
- 경고·어택 상태

일부 초자연현상은 **실제 귀신 위치와 무관하게** 플레이어 주변 또는 지정된 Spawn Point에
일시적인 귀신 모습을 생성할 수 있다.

## 4. 귀신 상태

귀신은 5개의 공통 상태를 가진다. 별도로 아이템에 의한 **강제 진정** 효과가 존재한다.

### 4.1 상태 요약

| 상태 | 지속 시간 | 어택 판정 | 공격 | 이동 | 초자연현상 |
| --- | --- | --- | --- | --- | --- |
| 평상시 | 조건 충족까지 | X | X | O | 낮은 빈도 |
| 활동 | 조건 유지되는 동안 | O (팀 평균 ≤ 60일 때만) | X | O | 높은 빈도 |
| 경고 | **5초** [확정] | X | X | O | 경고 연출 |
| 어택 | **30~90초** [임시] | X | **O** | O | — |
| 자연 진정 | **30초** [확정] | X | X | 제한적 | — |
| 강제 진정 | **10초** [확정] | X | X | 제한적 | X |

### 4.2 전체 상태 흐름 [확정]

```text
게임 시작
   ↓
[평상시] ↔ [활동]
              ↓ 어택 판정 성공
        [경고 5초]
              ↓
        [어택 30~90초]
              ↓
      [자연 진정 30초]
              ↓ 현재 조건 재검사
        ↙            ↘
   활동 조건 있음   활동 조건 없음
       [활동]         [평상시]
```

- **활동 상태는 어택 직전 상태를 의미하지 않는다.** 활동에 진입해도 어택 판정에 실패하거나
  어택 조건을 충족하지 못하면 계속 활동하거나 평상시로 복귀할 수 있다.
- 강제 진정은 위 흐름과 **별개 시스템**이며 어느 상태에서든 개입한다 → §4.8

### 4.3 평상시 [확정]

게임 시작 시의 기본 상태다. 귀신은 **반드시 평상시에서 시작한다.**

- 집 내부를 이동할 수 있다.
- 낮은 빈도로 초자연현상을 발생시킬 수 있다.
- 플레이어를 직접 공격할 수 **없다.**
- 어택 판정을 실행하지 **않는다.**

다음 중 **하나라도** 충족하면 즉시 활동 상태로 전환한다.

1. 팀 평균 정신력 **80 이하**
2. 청소 진행도 **40% 도달**
3. 귀신별 특수 조건 충족

### 4.4 활동 상태 [확정]

환경 간섭과 초자연현상 발생이 증가한 상태다. 사용 가능한 행동:

- 물건 흔들기 / 작은 물건 떨어뜨리기
- 문 열고 닫기 / 서랍 열기
- 조명 깜빡임 또는 끄기
- 벽·문 두드리는 소리 / 발소리
- 귀신 일시 출현

**활동 상태가 반드시 어택으로 연결되는 것은 아니다.**
팀 평균 정신력이 **60 이하**인 경우에만 기본 어택 판정을 실행할 수 있다.

### 4.5 경고 상태 [확정]

어택 판정이 성공하여 **어택 발생이 확정된** 상태다.

- 지속 시간: **5초**
- 경고 중에는 신규 어택 판정을 하지 않는다.
- 플레이어가 어택 발생을 인지할 수 있는 공통 연출을 제공한다 → §10.3
- 경고 종료 후 **어택 상태로 전환한다.**

> **해석 주의.** 원문에는 경고 도중 정신력이 회복되어 어택이 **취소되는 경로가 없다.**
> 따라서 경고에 들어간 어택은 취소되지 않는 것으로 읽는다. 강제 진정만이 이를 끊을 수 있다(§4.8).

### 4.6 어택 상태 [확정]

귀신이 실제로 플레이어를 탐지·추적·공격할 수 있는 상태다.

- 플레이어 탐지 활성화 → §8
- 수색·추격 AI 활성화 → §9
- 플레이어 공격 가능
- 어택 중 신규 어택 판정 **금지**
- 플레이어 한 명이 사망해도 **어택은 종료되지 않는다.**
- 귀신은 집 내부에서만 활동한다. 드릴 카·집 밖 플레이어는 공격할 수 **없다.**

지속·종료 규칙은 §7.5.

### 4.7 자연 진정 상태 [확정]

어택 종료 후 연속 재어택을 방지하는 상태다.

- 지속 시간: **30초**
- 신규 어택 발생 불가 / 경고 상태 진입 불가
- 플레이어 추격·공격 불가
- 30초 종료 후 **현재 활동 조건을 다시 검사한다.**

```text
활동 조건 존재 → 활동
활동 조건 없음 → 평상시
```

### 4.8 강제 진정 효과 [확정]

특정 아이템 사용으로 귀신에게 강제 적용하는 억제 효과다. **자연 진정과는 별개 시스템으로 관리한다.**

- 지속 시간: **10초**
- 진행 중인 어택 **즉시 종료**
- 신규 어택 발생 차단
- 활동 상태 진입 억제
- 공격 행동 불가
- 효과 종료 후 현재 조건을 재검사하여 평상시 또는 활동으로 전환

아이템 종류·소지 개수·사용 조건은 아이템 기획서에서 정의한다.

## 5. 정신력 연동

정신력 수치의 정의·증감·디버프·UI는 [정신력 시스템 기획서](sanity-system.md)가 단일 권위다.
이 문서는 **그 값을 어떻게 읽어 쓰는지**만 정의한다.

### 5.1 기본 규칙 [확정]

- 각 플레이어는 개인 정신력을 가진다.
- 일반 귀신의 공통 상태 전이와 어택 판정에는 **생존 플레이어의 팀 평균 정신력**을 사용한다.
- 일부 특수 귀신은 팀 평균 대신 특정 플레이어의 **개인 정신력**을 참조할 수 있다
  (개별 귀신 기획서에서 정의).

구현상 팀 평균의 출처는 `ISanityTeamService`이며, 귀신은 자체 정신력을 갖지 않는다 →
[ghost-prototype.md §3](../architecture/ghost-prototype.md)

### 5.2 정신력 구간 [확정]

| 팀 평균 정신력 | 귀신 행동 |
| --- | --- |
| 81~100 | 정신력에 의한 활동 진입 없음 / 어택 불가 |
| 61~80 | 활동 진입·유지 가능 / 어택 불가 |
| 31~60 | 활동 + **어택 가능** |
| 0~30 | 어택 가능 + 초자연현상 빈도 증가 + **귀신 특수 능력 사용 가능** |

### 5.3 구간별 규칙 [확정]

**80 이하** — 그 순간 평상시에서 활동으로 **즉시 전환**한다. 80 이하가 유지되는 동안
정신력에 의한 활동 조건도 유지된다. 80을 **초과**하고 다른 활동 조건이 없으면 평상시로 복귀할 수 있다.

**60 이하** — 어택 판정을 실행할 수 있다. **60 이하가 되었다고 즉시 어택이 발생하지는 않는다.**
정해진 주기마다 확률을 판정하고, 성공한 경우에만 경고 상태로 진입한다.

**30 이하** — 고위험 구간으로 취급한다.

- 초자연현상 발생 빈도 증가
- 귀신 특수 능력 사용 가능 (종류는 개별 귀신 기획서)
- 높은 어택 확률 적용

## 6. 행동 빈도와 초자연현상

### 6.1 기본 발생 규칙 [확정]

- 평상시에도 초자연현상이 발생할 수 있다.
- 활동 상태에서는 발생 빈도가 증가한다.
- 팀 평균 정신력 30 이하에서는 **추가로** 빈도가 증가한다.
- 상태별 실제 발생 주기는 프로토타입 테스트로 조정한다 [TBD].

### 6.2 청소 진행도 40% 트리거 [확정]

청소 진행도가 **최초로** 40%에 도달하면 귀신의 방해가 강해진다.

| 도달 시점의 상태 | 처리 |
| --- | --- |
| 평상시 | 즉시 활동 상태로 전환 |
| 활동 | 활동 유지 + **일정 시간 동안 방해 빈도 증가** |

빈도 증가 지속 시간은 원문 검증 항목(§12.2)에 **90초** [임시]로만 등장한다.

### 6.3 초자연현상 정의 [확정]

초자연현상은 귀신이 플레이어를 위협하거나 작업을 방해하기 위해 발생시키는 **비공격 행동**이다.
공격은 하지 않지만 방해하는 모든 현상을 초자연현상으로 정의한다.

- **초자연현상 자체로는 플레이어가 사망하지 않는다.**
  사망은 어택 상태에서 귀신에게 잡혔을 때만 발생한다.

역할:

- 공포 연출
- 정신력 감소
- 작업 방해
- 귀신 존재 위치 암시
- 플레이어 이동·행동 유도

### 6.4 현상 선정 방식 [확정]

```text
1. 현재 귀신 상태 확인
2. 초자연현상 발생 여부 판정
3. 현재 실행 가능한 초자연현상 Pool 확인
4. Pool 내부에서 랜덤 선택
5. 현상 실행
6. 직전에 실행한 현상은 다음 선택 Pool에서 제외
```

6단계로 동일 현상의 연속 발생을 방지한다.

### 6.5 초자연현상 종류 [확정]

| # | 현상 |
| --- | --- |
| 1 | 주변 물건 흔들기 |
| 2 | 작은 물건 떨어뜨리기 |
| 3 | 정리된 소품 위치 변경 |
| 4 | 문 또는 서랍 열고 닫기 |
| 5 | 전등 이상 |
| 6 | 가전제품 작동 |

## 7. 어택 타임

### 7.1 발동 조건 [확정]

어택 발생 경로는 두 가지다.

1. **일반 어택 판정** — 일정 주기마다 확률로 판정
2. **특수 어택 Trigger** — 특정 조건 충족 시 즉시 100% 발동

일반 어택 판정의 전제 조건(**모두** 만족):

- 귀신이 **활동 상태**일 것
- 팀 평균 정신력 **60 이하**일 것
- 경고·어택·자연 진정·강제 진정 상태가 **아닐** 것

### 7.2 기본 어택 판정 [임시]

- 판정 주기: **10초**

```text
10초 경과
   ↓
현재 어택 가능 조건 검사
   ↓ 충족
정신력 구간별 Attack Roll
   ├─ 성공 → 경고 상태
   └─ 실패 → 10초 후 재검사
```

어택이 시작된 순간부터 다음 어택 판정을 **중지**하고, **자연 진정이 종료된 이후에 재개**한다.

### 7.3 정신력별 어택 확률 [임시]

| 팀 평균 정신력 | 10초당 어택 확률 |
| --- | ---: |
| 61~100 | 0% |
| 51~60 | 20% |
| 41~50 | 40% |
| 31~40 | 60% |
| 0~30 | 80% |

정신력이 낮아질수록 단계적으로 증가한다. 수치는 프로토타입 플레이 결과로 조정한다.

### 7.4 특수 어택 Trigger [확정]

다음 상황에서는 10초 주기를 기다리지 않고 **즉시 100% 어택**을 진행한다.

- 저주받은 오브젝트 조작
- 귀신별 특수 조건
- 특정 콘텐츠 Trigger

> **원문 미완결.** "단, 이미 공격 상태일 때 특수 어택 Trigger 행동을 했다면," 에서 문장이 끊긴다.
> 이미 어택 중일 때의 처리(무시 / 지속시간 연장 / 재시작)는 [§13 G-2](#13-미결정-목록)에서 대기 중이다.

### 7.5 지속 시간과 종료 [임시]

| 항목 | 값 |
| --- | --- |
| 최소 어택 지속시간 | **30초** |
| 최대 어택 지속시간 | **90초** |
| 조기 종료 정신력 기준 | 팀 평균 **70 이상** |

- 최소 30초 이전에는 **아이템을 사용하지 않는 한 절대 종료되지 않는다**(강제 진정 아이템 → §4.8).
- 30초 경과 이후 팀 평균 정신력이 **70 이상**으로 회복되면 조기 종료할 수 있다.
- 정신력이 회복되지 않아도 **90초 도달 시 강제 종료**한다.
- 플레이어가 한 명 사망하더라도 어택은 계속 유지된다.

추가 조기 종료 조건은 [TBD] → [§13 G-9](#13-미결정-목록)

## 9. 추격·수색 AI

### 9.1 기본 흐름 [확정]

```text
집 내부 배회
   ↓ 플레이어 탐지
추격
   ↓ 플레이어를 놓침
마지막으로 확인한 위치 기억 → 그 위치까지 이동
   ↓
7초 수색
   ├─ 재탐지 → 추격
   └─ 실패  → 집 내부 배회
```

### 9.2 추격 [확정]

- 탐지한 플레이어를 추격 대상으로 지정한다.
- 추격 중 시야·소리로 위치를 계속 갱신한다.
- 놓쳐도 위치 정보를 즉시 삭제하지 않고 **마지막으로 확인한 위치**를 저장해, 그 근처를 맴돌며 찾는다.

### 9.3 수색 [확정]

마지막 확인 위치까지 이동한 뒤 **7초 동안** 주변을 수색한다. 수색 중:

- 시야 재탐지 가능
- 이동 소리 재탐지 가능
- 주변 은신처 검사 가능 → §9.5

재발견하면 즉시 추격으로 전환한다. 7초 안에 발견하지 못하면 수색을 종료하고 집 내부 배회로 돌아간다.

### 9.4 문 [확정]

귀신은 어택·수색 중 **일반 방문을 직접 열 수 있다.**
따라서 방문만 닫고 방 안에 있는 것으로는 완전한 은신이 되지 않는다.

### 9.5 은신처 [확정 / 확률은 임시]

공통 은신처: **옷장 · 침대 밑 · 책상 밑 · 땅속**

**일반 은신처** — 귀신은 수색 중 근처 은신처를 발견하면 **30% 확률로 검사한다** [임시].
귀신은 플레이어가 그 안에 있다는 정보를 알고 검사하는 것이 아니라, 주변의 가능한 은신처를
**랜덤하게** 확인한다. 따라서 일반 은신처는 **완전한 안전지대가 아니다.**

> **G-8 판정 시점·주기·재검사 — 임시 구현 (사용자 확정 2026-08-31, 여전히 미정).**
> 원문·구현 모두 "수색 중 은신처에 **최초로** 접근했을 때 1회만" 30% 검사하는 것으로 임시
> 확정했다. 이번 수색(7초) 동안 같은 은신처를 다시 확인하지는 않는다. **정식 규칙(주기적
> 재판정 여부 등)은 여전히 미정**이며, 이건 플레이 테스트 전까지 쓰는 임시값이다 →
> [ghost-prototype.md §4](../architecture/ghost-prototype.md).

**땅속 은신** — 두더지 플레이어의 굴착 스킬. 정상적으로 활성화된 동안에는 귀신에게
**탐지·공격되지 않는다.** 쿨타임·최대 유지시간 등은
[두더지 스킬 시스템 기획서 §5](mole-skill-system.md)에서 정의한다(초안 — 최대 5초 [임시], 쿨타임 [TBD]).

## 10. 공통 연출

상태 변화를 플레이어가 시청각으로 인지할 수 있게 한다.
**연출은 게임 판정과 분리한다.** 서버가 상태·사건을 확정하고 각 클라이언트가 재생한다.

### 10.1 평상시 [확정]

- 별도의 상태 UI **없음**
- 낮은 빈도의 초자연현상으로 존재를 간접 표현

### 10.2 활동 [확정]

귀신 상태를 **직접 UI로 표시하지 않는다.** 다음 변화로 간접 전달한다.

- 초자연현상 빈도 증가
- 물건 간섭 증가
- 이상음 증가
- 조명·환경 변화 증가

플레이어가 귀신 행동을 관찰해 위험 증가를 판단하게 한다.

### 10.3 경고 [확정]

어택 확정을 전달해야 하므로 다른 상태보다 **명확한 공통 신호**를 사용한다. 지속 5초.

- **심장 박동 소리** — 어택이 가까워졌음을 전달하는 핵심 청각 연출
- 조명 이상
- 공통 경고 사운드 또는 환경음 변화

세부 사운드 디자인·VFX는 추후 연출/사운드 기획에서 정의한다 [TBD].

### 10.4 어택 [확정]

- 귀신 본체 시각적 노출
- 귀신 전방의 **빨간 원뿔형 시야 표시** → §8.2
- 추격 관련 사운드 활성화
- 경고 연출 → 어택 연출로 전환

### 10.5 자연 진정 [확정]

어택 관련 연출을 제거하고 환경을 점차 평상시 수준으로 복원한다.

- 빨간 시야 표시 제거
- 추격 사운드 종료
- 경고·어택 관련 효과 종료

### 10.6 강제 진정

아이템별 시각·청각 효과를 적용한다. 세부 연출은 아이템 기획서에서 정의한다 [TBD].

## 11. 예외 처리

### 11.1 드릴 카 세이프 존 [확정]

드릴 카는 귀신으로부터 안전한 세이프 존이다.

- 귀신은 집 밖으로 이동할 수 없고, 드릴 카 내부로 진입할 수 없다.
- 드릴 카 내부 플레이어는 **탐지 대상에서 제외**하며 공격받지 않는다.
- 한 명이 드릴 카로 이동해도 다른 플레이어에 대한 어택은 종료되지 않는다.
- **모든 플레이어가 집에서 나가도 귀신의 현재 상태는 초기화되지 않는다.**
- 어택 중 전원이 집 밖으로 나가도 **어택 타이머는 계속 진행**한다.
- 어택 종료 전에 집 안으로 재진입하면 현재 어택 상태의 영향을 다시 받는다.

### 11.2 플레이어 사망 [확정]

한 명이 어택 중 사망해도 **어택을 종료하지 않는다.**
생존 플레이어가 남아 있으면 귀신은 기존 규칙대로 계속 탐지·수색한다.

### 11.3 중복 어택 방지 [확정]

다음 상태에서는 신규 어택 판정을 실행하지 않는다.

- 경고 · 어택 · 자연 진정 · 강제 진정

따라서 하나의 어택 진행 중 추가 어택이 중첩되는 상황은 발생하지 않는다.

### 11.4 추가 귀신 [TBD]

특수 콘텐츠로 추가 귀신이 생성될 때의 규칙은 프로토타입 이후 결정한다.

- 복수 귀신이 동시에 어택 가능한지
- 귀신별 상태를 독립적으로 관리하는지
- 하나의 공통 어택 상태를 공유하는지

## 12. 프로토타입 범위

### 12.1 반드시 만들어야 하는 시스템

> 아래 "현재" 열은 2026-08-30 재구현 기준이다. 구현 구조·수치 대응은
> [ghost-prototype.md](../architecture/ghost-prototype.md)가 단일 권위다.

| 시스템 | 구현 수준 | 현재 |
| --- | --- | --- |
| 플레이어 기본 이동 | 걷기 / 달리기 / 웅크리기 | **3단계 전부 구현** (걷기 5·달리기 ×1.4=7·웅크리기 3.5 m/s). 웅크리기는 귀신 소리 탐지 제외. `RunSpeedThreshold` 6m/s로 걷기(6m 반경)·달리기(12m 반경) 구분 |
| 정신력 시스템 | 개인 정신력 + 팀 평균 계산 | 구현됨 |
| 청소 진행도 | 실제 청소 대신 테스트용 단순화 가능 | F1 디버그 스텁 (수동 0~100%, 40% 일회성 트리거) |
| 귀신 상태 시스템 | 평상시 / 활동 / 경고 / 어택 / 자연 진정 | 5상태 + 강제 진정 구현, **전이는 팀 평균 정신력·청소 40%·F1 강제 기반** |
| 귀신 이동 AI | 집 내부 배회 | 상자 범위 무작위 지점 배회 구현 (NavMesh 없음) |
| 귀신 행동·초자연현상 | 대표 3~5개 | **구현** — §6.4 선정 루프 + 8종 중 6종 활성(흔들기·떨어뜨리기·문·서랍·조명·일시 출현). 소리 2종은 오디오 대기. 목격 시 정신력 −15 연결 완료(G-6) |
| 어택 판정 | 정신력별 확률 + 10초 판정 | **구현** — §7.3 확률표 + 10초 주기 |
| 플레이어 탐지 | 시야 + 걷기·달리기 소리 | 시야(15m/120°)+근거리 구현. 서버 속력 추정으로 달리기 12m / 걷기 6m / 웅크리기 무음 |
| 추격·수색 AI | 추격 → 마지막 위치 → 7초 수색 | **구현 (수색 7초)** |
| 은신 시스템 | 일반 은신처 + 땅속 은신 | **일반 은신처 임시 구현** — 방마다 상자 경계 1개, 최초 접근 시 1회 30% 검사(G-8 판정 시점만 임시 확정, 나머지 미정). 땅속 은신은 기존 굴착 스킬로 구현됨 |
| 사망 처리 | 잡히면 사망, 어택은 계속 | 잡히면 `SanityNetworkState.ServerMarkDead()`, 어택 유지 |
| 드릴 카 세이프 존 | 들어가면 탐지·공격 불가 | **임시 구현** — 정식 드릴 카 없이 현관 앞 상자(`DrillCarSafeZone`). 그 안이면 탐지·잡힘 제외. §11.1 세부(전원 이탈 시 타이머, 재진입 처리)는 미구현 |
| 상태별 연출 | 경고/어택을 구분할 최소 연출 | 본체는 경고·어택만 노출, 경고 점광원 맥동 / 어택 빨간 점광원 + 지면 부채꼴 시야 표시 |
| 디버그 UI | 현재 수치와 State 확인 | F1 HUD 귀신 섹션 구현 (Host 전용) |

디버그 UI 표시 예시:

```text
Ghost State      : ACTIVE
Team Sanity      : 57
Attack Check     : 4.2 sec
Cleaning Progress: 43%
```

### 12.2 프로토타입 검증 항목

다음 값을 플레이 테스트로 우선 검증하고 **수정 가능**하다.

| # | 검증 질문 |
| --- | --- |
| 1 | 정신력 감소 속도 대비 80 / 60 / 30 기준이 적절한가 |
| 2 | 10초 주기 Attack Roll이 지나치게 잦거나 느리지 않은가 |
| 3 | 정신력별 20 / 40 / 60 / 80% 어택 확률이 과도하지 않은가 |
| 4 | 최소 30초 / 최대 90초 어택이 실제 플레이에서 적절한가 |
| 5 | 자연 진정 30초가 작업 재개 시간을 충분히 제공하는가 |
| 6 | 경고 5초가 은신 행동을 수행하기에 충분한가 |
| 7 | 일반 은신처 검사 확률 30%가 적절한가 |
| 8 | 수색 7초가 지나치게 짧거나 길지 않은가 |
| 9 | 청소 40% 이후 **90초** 행동 증가가 과도하지 않은가 |
| 10 | 어택 중 빨간 시야 표시가 회피를 돕되 공포감을 줄이지는 않는가 |

### 12.3 현재 구현과의 차이

2026-08-30 재구현은 이 기획서 1.0을 기준으로 처음부터 작성했고, `[임시]` 수치는
`GhostPrototypeSettings` 에셋에 노출했다. 대응 현황은
[ghost-prototype.md §8](../architecture/ghost-prototype.md)이 단일 권위다. 남은 차이만 적는다.

| 항목 | 이 기획서 | 재구현 |
| --- | --- | --- |
| 시야 거리·각도 | 거리·각도 TBD (G-3) | 15m / 120° (SO 기본값, 조정 대기) |
| 근거리 감지 | **기획서에 없음** | 3m (SO, 0으로 끄면 사라짐) |
| 소리 탐지 | 달리기 > 걷기 > 웅크리기 | 서버 속력 추정으로 달리기 12m / 걷기 6m / 웅크리기 무음. `RunSpeedThreshold` 6m/s (걷기 반경만 확정, G-4 잔여) |
| 시야 표시 | 어택 중 빨간 원뿔 | 어택 중 **지면에 눕힌** 빨간 부채꼴 |
| 배회 | 집 내부 배회 | 스포너가 넘긴 상자 범위에서 무작위 지점 배회 (NavMesh 없음) |
| 은신처 | 4종(옷장·침대 밑·책상 밑·땅속) + 30% 검사 | **1종만 임시 구현** — 정식 가구가 아직 없어 옷장·침대 밑·책상 밑을 구분하지 않고 방마다 순수 상자 경계 하나(`HidingSpot`)로 통일. 30% 검사는 "최초 접근 시 1회"만(G-8 판정 시점 임시 확정, 재검사 여부 등은 미정) |
| 초자연현상 | 9종 Pool, 직전 현상 제외 | **§6.4 선정 루프 구현** — 8종 enum 중 6종 활성. 소리 2종(#7·#8)은 `SoundPhenomenaEnabled=false`, #3·#6·#9 는 범위 밖. 발생 주기는 SO `[TBD] G-13`. **목격 시 정신력 −15 연결 완료(G-6)** — 종류 불문, 거리·각도·가림으로 판정. 테스트베드는 정식 시체·이벤트 시스템 전까지 존치 |
| 드릴 카 | 세이프 존 | **세이프 존만 임시 구현** — 현관 앞 상자(`DrillCarSafeZone`), 안이면 탐지·잡힘 제외. 드릴 카 본체·§11.1 세부는 미구현 |
| 활동도(0~100) | **기획서에 개념이 없음** | **제거함 (G-5)** — 상태 + 정신력 구간만 |
