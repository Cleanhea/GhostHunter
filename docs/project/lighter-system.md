## 3. 규칙

- **보유** (2026-09-29) — 라이터는 시작 지급이 아니다. 인게임 로비 상점에서 **철제 라이터 $10**을 플레이어별로 사야 쓴다.
  사기 전에는 퀵슬롯 휠에서 흐리게 보이고 골라도 장착되지 않는다 → [stage-system.md §2.2](stage-system.md).
- **켜짐** — 퀵슬롯(Tab)에서 라이터를 골라 **들고 있는 동안 켜진다.** 다른 슬롯(대걸레·드라이버·맨손)을 고르면 집어넣어 꺼진다.
  따로 누르는 키는 없다 [구현 선택 — §5].
- **연료** — 총량 100. 켜져 있는 동안 초당 0.8씩 감소(약 2분), 스테이지 씬에서만 줄어든다. 0이 되면 꺼진다.
  드릴카 안에서는 초당 5씩 충전되고, 충전 중에는 켜져 있어도 줄지 않는다. 라이터를 든 채 연료가 차면 다시 붙는다. [TEMP]
- **사용 불가** — 사망하면 꺼진다. 은신처 상자 안·침대 밑에서는 켜지지 않는다(헤드라이트와 같은 규칙, 귀신 기획서 §9.3.1).
- **땅굴** — 땅굴 안에서 라이터가 켜져 있으면 숨은 것이 아니다 → 귀신이 감지한다(헤드라이트와 같은 규칙, 두더지 스킬 §5.2.1 ②).
- **어둠 판정** — 어둠 = 자기 헤드라이트와 라이터가 **모두** 꺼진 상태. 드릴카 안은 어둠이 아니다(정신력 기획서 §4.3).
- 다른 플레이어의 라이터 불빛도 보이지만 내 어둠 판정에는 들어가지 않는다(헤드라이트와 같다).

## 4. 표시

- **불빛** — 손(화면 오른쪽 아래) 위치의 흔들리는 주황 점광원. 반경 3.5m · 밝기 0.9(2026-10-04 사용자 요청으로 4.5m·1.6 에서 낮춤) · 흔들림 ±18% · Soft 그림자.
  헤드라이트(원뿔 14m)와 달리 발밑과 주변을 둥글게 비춘다. [TEMP]
- **모양** — 작은 검은 몸체 + 주황 불꽃(자리표시자 도형). 실제 모델은 아트 대기.
- **연료 UI** — 두더지 스킬 UI와 같은 원형 게이지, 헤드라이트 충전 칸 **바로 아래**에 "라이터 nn%".
  라이터를 들고 있는 동안, 그리고 드릴카에서 연료가 차는 동안 보인다.
- **효과음** — 꺼낼 때(불 붙음)·집어넣을 때·연료 없이 꺼냈을 때 세 슬롯. 음원은 비어 있다(대기).
