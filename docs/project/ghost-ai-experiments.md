# 귀신 AI 실험 기능

작성일: 2026-09-30. 사용자 요청에 따라 추천 요소를 임시 적용하고 개별 토글로 비교한다.
공통 정식 규칙은 [ghost-system.md](ghost-system.md), 실험 구현은
[ghost-prototype.md](../architecture/ghost-prototype.md)와 이 문서에 기록한다.

## 1. 사용법과 기본값

1. Host로 세션을 시작해 귀신이 스폰된 상태에서 **F2**를 누른다.
2. **귀신 → AI experiments** 그룹을 열고 아래 토글을 바꾼다.
3. **Ai Experiments Enabled**를 OFF하면 기존 탐지·좌표 기반 타깃 선정·랜덤 수색·현상 간격으로 비교한다.
4. 세부 수치는 **AI experiment tuning** 그룹에서 바꾼다. 영구 기본값은
   Assets/Settings/Gameplay/GhostPrototypeSettings_Default.asset 인스펙터에서 저장한다.

Tab 귀신 섹션에도 F2 안내를 표시한다. F2는 기존 TuningHud가 직렬화 bool 필드를 자동으로 표시한다.
서버의 설정만 AI 판정에 사용한다. 게스트 로컬 설정 변경은 서버 AI를 변경하지 않는다.
기존 튜닝 창의 되돌리기는 창이 설정을 처음 읽은 시점의 값을 복원한다.
에디터에서는 SO 인스턴스 변경이 Play 종료 후에도 남을 수 있다.

| F2 / Inspector 토글 | ON 동작 | OFF 동작 |
| --- | --- | --- |
| Ai Experiments Enabled | 아래 개별 선택 적용 | 모든 실험 기능 비활성 |
| Evidence Tracking Enabled | 감지 가능한 후보만 선정. 시야·이동 소리가 끊기면 마지막 관측 위치를 수색 | 기존 집 안 최근접 좌표 추격 |
| Utility Search Enabled | 도주 방향·미확인 칸·경로 이동 시간으로 수색 후보 평가, 가까운 문 후보 포함, 도착 후 두리번 | 기존 주변 무작위 수색 |
| Predictive Chase Enabled | 관측 속도로 짧은 선행 목적지 예측 | 마지막 위치를 바로 추격 |
| Impact Investigation Enabled | 어택 중 가구 충돌 위치 조사 | 가구 충돌 단서 무시 |
| Tension Pacing Enabled | 최근 위협·일시 출현 후 초자연현상 타이머 진행을 완화 | 기존 타이머 속도 |

기본 설정 **에셋은 전체·개별 ON**이다. 새로 생성하는 설정 SO의 전체 토글 기본값은 OFF라서
기존 순수 상태 테스트와 별도 설정이 자동으로 바뀌지 않는다. 전체 OFF는 개별 선택을 보존한다.

## 2. 적용 범위

이번 요청은 정식 기획 수치 확정 대신 **토글로 되돌릴 수 있는 실험 모드**를 승인한 것으로 기록한다.
Evidence Tracking ON은 공통 기획 §9.2의 벽 너머 최근접 좌표 타깃 선정과 §9.3의 수색 시작 조건을
시험적으로 바꾼다. 기존 기획을 기준으로 비교하려면 전체 또는 해당 개별 토글을 끈다.
어택 발동 조건·정신력 구간·어택 지속시간·자연 진정 시간·은신의 안전 판정은 유지한다.

### 단서와 예측

GhostTrackingMemory는 대상 ID·마지막 관측 위치·평면 속도·관측 시각을 보관한다.
관측은 기존 타깃 선정 주기(0.2초)에 수행하고, 새 타깃은 이전 타깃의 속도를 물려받지 않는다.
현재 관측 가능한 후보끼리는 기존 최근접·1m 히스테리시스를 사용한다.
놓치면 실제 좌표를 갱신하지 않고 수색한다. 기존 걷기·달리기 청각 반경은 유지한다.

단서 확신도는 기본 8초 동안 선형 감소한다. 예측은 기본 0.6초·최대 2.5m, 관측 속력은 최대 8m/s다.
예측 지점이 집 경계를 벗어나거나 다른 층·NavMesh 바깥·NavMesh ray로 막힌 곳이면 마지막 위치를 쓴다.
단서 추적 ON의 일반 포획에는 같은 층·시야선 검사를 추가해 벽 너머·바로 위층 근거리 포획을 방지한다.

### 수색

기본 8개 랜덤 후보와 주변에서 가장 가까운 문 1개를 비교한다.
점수는 도주 방향 정렬 × 단서 확신도 × 방향 가중치 + 미확인 정도 × 방문 가중치
− 경로 이동 시간 × 이동 비용 가중치다. 기본 가중치는 각각 2 / 3 / 0.4다.
완전한 NavMesh 경로와 같은 층 조건을 만족하는 후보만 사용한다.
기존 마지막 위치 주변 반경·10초 수색 시간은 유지한다. 전체 방 연결 그래프는 이번 범위에 없다.

GhostSearchMemory는 확인한 격자 칸 최대 32개를 고정 배열로 기억한다.
도착 또는 경로 실패 지점은 재방문 우선순위를 낮추고, 도착 시 기본 0.7초 두리번거린다.
새 수색·어택 종료·토글 변경에서는 수색 기록과 대기 동작을 정리한다.

### 가구 소음

FurnitureNetworkPhysics.ServerImpactReported는 서버 충돌의 접촉 위치·법선 상대 속력을 전달한다.
배치 보호 시간·호스트 복구 중 충돌은 전달하지 않는다. 내구도 계산과 물리 권위는 기존대로다.
귀신은 어택 중 배회·일반 수색에서만 단서를 받고, 추격·목격된 은신 확인 중에는 무시한다.

임시 기준은 최소 2m/s, 청각 반경 14m, 벽·문 가림 시 반경 × 0.5, 접수 간격 1초다.
직선거리와 NavMesh 경로 길이를 모두 검사한다. 단서는 충돌 위치 조사만 시작하며
플레이어를 특정하거나 완전히 숨은 플레이어를 노출하지 않는다.
충돌 이벤트는 귀신 서버 spawn에서 구독하고 despawn·destroy에서 해제한다.
마이크 음성·청소 작업·문 닫힘 소음 추가는 이번 범위에 없다.

### 연출 간격

경고·어택, 가까운 귀신 본체 목격, 일시 출현이 내부 연출 압박 계수에 반영된다.
압박은 기본 15초 동안 완화되며 초자연현상 타이머의 진행을 최대 2배 늦춘다.
계수는 연출 주기에만 쓰인다. 어택 상태 기계·정신력 감소량·현상 종류 Pool은 유지한다.
개별 OFF면 타이머 진행 속도가 즉시 기본값으로 돌아간다. 강제 현상 실행은 즉시 발생한다.

## 3. 은신과 복구

못 본 일반 은신·완전히 숨은 침대 밑·안전한 굴착은 기존대로 탐지와 일반 포획에서 제외한다.
목격한 일반 은신·굴착은 기존 추적을 유지하고, 단서 모드에서 목격한 침대 진입도 별도로 기억한다.
목격된 은신은 일반 단서 확신도와 수색 만료로 면제하지 않는다.
호스트 복구는 기존 마지막 위치·추격 상태를 사용하고, 관측 속도·수색 방문 기록·미접수 소음은 초기화한다.
목격된 침대 대상은 기존 타깃 스냅샷 슬롯으로 보존한다. 새 어셈블리·패키지·씬·프리팹 배선은 추가하지 않는다.

## 4. 검증

- Unity 복제본 컴파일 통과.
- 새 기억·점수·토글·연출 타이머 EditMode와 기존 귀신·가구 충돌 회귀 테스트 실행.
- Local Host PlayMode에서 단서 상실→수색, 전체 OFF→좌표 추격, 비목격 은신 안전,
  가림 포획 차단, 소음 조사/무시, 이벤트 해제, 목격/비목격 침대 은신 검증.
- 최종 검증: **EditMode 65/65·PlayMode 16/16 통과** (2026-09-30, 검증 복제본).
- 추가 침대 테스트의 첫 실행은 픽스처의 ILocalPlayerContext 누락으로 실패했다. 등록·해제를 보완한 뒤 재실행해 통과했다.
- 실제 Stage1 체감·연출·계단 경로와 Steam 다인 접속은 확인 필요.

## 5. 플레이 확인 순서

1. Host에서 기본 ON으로 문 모퉁이 뒤에서 조용히 이동해 마지막 위치를 수색하는지 확인한다.
2. 추격 중 이동 방향을 바꿔 예측 목적지가 벽을 넘거나 지나치게 앞서지 않는지 확인한다.
3. 귀신이 어택 중 배회할 때 가구를 떨어뜨려 충돌 위치를 조사하는지 확인한다.
4. 못 본 은신은 안전한지, 들어가는 것을 본 침대·굴착은 계속 추적하는지 확인한다.
5. 전체 OFF와 개별 토글을 번갈아 바꾸며 추격·수색·현상 간격의 체감을 비교한다.

모든 새 수치는 [TEMP]다. 플레이 결과를 바탕으로 정식 채택 여부와 값을 사람이 결정한다.
