## 이동 가구

`Assets/Prefabs/Furniture/Stage2/`의 18개 프리팹은 원본 OBJ의 메시·재질을 사용한다.
TV장·TV·낮은 탁자·소파·안락의자·책장 2개·벽 책상·키큰 수납장·화장대·스툴·서랍장·옷장 4개·유리 탁자·주방 카트다.
같은 자리에 있던 정적 원본 부분만 씬에서 비활성화해 이중 렌더·충돌을 피한다. 붙박이 주방과 욕실은 고정이다.

기존 서버 물리·내구도·잡기/차징/발사·2인 운반·윤곽선·탐지·반출·정산·복구 경로를 사용한다.
질량/투척/내구도 설정은 대응하는 기존 가구 정의를 재사용한다. 분해 레시피는 새로 만들지 않았다.
가구는 런타임 Instantiate로 만들지 않고 씬 프리팹 인스턴스로 둔다. 기존 가구 배치기가 원본 위치의 전용 후보에 배치한다.
TV는 원본처럼 높은 위치에 있고, 스툴은 화장대 아래의 받침 관계를 명시한다.
원본에서 겹친 거울 옷장은 바깥쪽으로 1.5cm 이동했고, 화장대 충돌체는 상판·뒤판으로 나눠 스툴이 끼지 않게 했다.

반출 목표는 **18개 전부**다(2026-11-09 사용자 확정). 각 가구의 전용 풀/후보를 하나씩 두고 모두 목표로 지정한다.
포장 비율/시간/속도는 Stage1의 기존 설정(85%·1초·0.3m/s)을 재사용한다.
