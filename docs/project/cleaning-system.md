# 청소 시스템

## 1. 확정 범위 (2026-09-12 사용자 요청)

- 퀵슬롯 한 칸을 **대걸레**로 사용한다.
- 대걸레를 장착하고 **마우스 좌클릭**하면 조준한 얼룩이 닦여 사라진다.
- 현재 맵에 얼룩을 랜덤 배치할 수 있고 **디버그 HUD에서 초기화**할 수 있어야 한다.
- **얼룩 상세 규칙은 추후 업데이트**한다. 가구 완료 판정과 진행도 계산도 이번에 정하지 않는다.

## 2. 프로토타입 구현 해석

정식 밸런스로 확정한 규칙이 아니라 위 요구를 플레이할 수 있게 만든 임시 형태다.

| 항목 | 임시 구현 |
| --- | --- |
| 슬롯 | 12시(0번) 대걸레, 6시(2번) 기존 더미를 맨손으로 표시. Tab 홀드·선택·해제 |
| 클릭 | 한 번 누를 때 조준한 얼룩 한 개를 제거. 길게 누르기·누적 청소량은 없음 |
| 대걸레 표시 | 소유자 시점에 단순 메시 표시, 클릭 시 짧은 닦기 동작. 다른 플레이어의 장착 연출 없음 |
| 사거리 | 3m [TEMP], 벽·가구로 가려진 얼룩은 청소 불가 |
| 닦임 연출 | 0.3초 [TEMP] 동안 한 방향으로 지워짐. 제거 판정 자체는 서버에서 즉시 확정 |
| 요청 간격 | 0.15초 [TEMP], 반복 RPC 방지용 |
| 얼룩 | B안 바닥 후보에서 최대 12개 [TEMP]. 벽·가구와 겹치는 후보는 제외 |
| 배치 범위 | 기존 B안 가구 배치의 Floor 후보. 현재 모든 방·벽·천장을 포괄하지 않음 |
| 초기화 | F1 접속 HUD → 청소 → `얼룩 초기화 · 랜덤 재배치`. Host 전용 |
| 후보 부족 | 배치 가능한 수만 배치하고 HUD에 실제 수/요청 수 및 부족 상태 표시 |
| 탐지 연결 | 더러운 얼룩만 Q 탐지의 분홍색 대상으로 활성화. 닦은 얼룩은 탐지에서 제외 |

대걸레 장착 중 좌클릭은 청소 입력이며 가구 잡기와 중복되지 않는다. 맨손을 선택하면 기존
가구 잡기를 사용한다. 사망·메뉴·굴착·휠 잠금 중 청소 입력을 받지 않는다. 얼룩 위치·제거·복원은
서버가 결정하고 모든 접속자에게 복제한다. 초기화 전에 발송된 청소 요청은 새로운 배치에 적용하지 않는다.

## 3. 미정 유지

- 얼룩 종류·생성 조건·분포·정식 수량·크기·누적 청소량·도구 상세 룰.
- 개별 가구의 작업 대상 여부와 **반출 완료 판정**(MG-22).
- 얼룩과 가구를 합산하는 **진행도 계산** 및 승패 연결(D-14).
- 귀신 청소 40% 트리거 연동. F1의 기존 `청소 +10%`는 별도 귀신 테스트 스텁으로 유지한다.
