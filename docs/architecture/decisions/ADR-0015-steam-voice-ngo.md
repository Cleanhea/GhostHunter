# ADR-0015: Steam Voice 캡처와 NGO 근접 음성 중계

- 상태: Accepted
- 날짜: 2026-09-17

## 배경

사용자가 근접 음성 기획서 구현을 요청했고 Steam Voice·기본 오픈 마이크·PTT·수직 컷·가구 제외를
확정했다. 추가 확인에서 생존/사망 채널 분리, 사망자 전역, 로비/타이틀 음성 없음,
귀신 탐지 비연동, 12m 중계 여유와 녹음 저장 없음도 승인했다.

## 결정

Steam Voice는 캡처와 코덱에만 사용한다. 전송은 플레이어 NetworkBehaviour의 NGO Unreliable RPC로
통일해 Steam P2P와 Local UTP 모두 같은 중계 경로를 사용한다. 계약에는 Steamworks 타입을 노출하지 않는다.
캡처는 Bootstrap 수명이며 소유 플레이어가 있는 동안만 활성화한다. 참여자와 사용자 조절 상태는 Game 수명이다.

서버는 송신 소유자·크기·속도·생존 상태·가청 범위를 검증하고 대상 그룹으로 중계한다.
클라이언트는 최종 XZ/높이/가림 감쇠와 재생을 맡는다. 12m 안에서 변조 클라이언트가 벽을 무시할 수 있는
한계는 승인된 비용이다. 서버 디코딩·혼합은 도입하지 않는다.

개발용 사인파는 별도 테스트 코덱이며 릴리스 서버에서 거부한다.
런타임 사용자 옵션은 PlayerPrefs, 개인 뮤트는 세션 상태다. 녹음 파일은 생성하지 않는다.
512B 안에 들어가는 완전한 압축 블록만 전송하며 MTU 초과 블록은 드롭한다.

## 결과와 재검토

새 패키지·레이어·asmdef 경계는 필요 없다. NativeArray를 위해 기존 Unity.Collections 어셈블리를 참조한다.
Player 네트워크 구성 변경에 따라 프로토콜 지문은 2로 올라간다.
Steam 없이 실제 마이크를 캡처할 수 없으므로 개발 사인파와 자동 테스트를 제공한다.
실제 Steam 프레임 크기·첫 음절·4인 SDR 지연을 측정해 512B 드롭이 문제가 되면 제한된 분할 전송을 재검토한다.
게임 내 입력 장치 선택, 자동 마이크 오류 분류, 신고/녹음, 전역 오디오 믹싱 정책은 추가하지 않는다.
