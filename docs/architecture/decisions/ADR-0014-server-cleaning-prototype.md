# ADR-0014: 씬 얼룩 풀의 서버 배치와 청소 상태 복제

- 상태: Accepted
- 날짜: 2026-09-12

## 배경

사용자는 퀵슬롯 대걸레·좌클릭 청소·현재 맵 랜덤 얼룩·HUD 초기화를 요청했다.
정식 얼룩 규칙과 가구 완료 판정·진행도는 후속 결정이다.

## 결정

기존 서버 권위 및 씬 배치 원칙을 적용한다. 얼룩은 재사용 프리팹을 씬 풀에 배치하고, 서버가
위치·회전·배치 여부·제거 여부·배치 세대를 하나의 NetworkVariable 상태로 복제한다.
NetworkTransform과 런타임 스폰/파괴를 추가하지 않는다. 초기화는 풀의 재배치·복원이다.

장착 요청은 소유 플레이어의 RPC로 처리하고 서버가 공유 로드아웃에 대조한다. 결과는 소유자에게만
회신하여 퀵슬롯의 로컬 표시 방침을 유지한다. 청소 RPC도 서버에서 거리·가림·상태·배치 세대를
재검증한다. 진행도·귀신 40% 스텁에는 연결하지 않는다.

## 결과

후접속자도 현재 얼룩 상태를 받으며, 초기화 이전의 지연된 클릭이 새 얼룩에 적용되지 않는다.
씬 풀 수량 이상의 얼룩이 필요하면 에디터 설치로 풀을 늘려야 한다. 배치 후보·수량·도구 동작은
프로토타입 설정으로 분리하며 정식 기획 확정 시 교체한다.
